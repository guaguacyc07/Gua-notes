# Vim 核心常用操作
## 1. 三大模式切换
| 操作             | 效果                                                      |
| ---------------- | --------------------------------------------------------- |
| 打开文件默认     | 命令模式（只能输命令，不能打字）                          |
| 命令模式按 `i`   | 进入插入模式（可正常编辑文字，左下角显示 `-- INSERT --`） |
| 任意模式按 `Esc` | 回到命令模式                                              |
| 命令模式按 `:`   | 进入末行模式（执行保存、退出等指令）                      |

## 2. 命令模式 - 光标快速移动
| 按键         | 作用                                         |
| ------------ | -------------------------------------------- |
| `h j k l`    | 左、下、上、右（方向键也能用，这是标准指法） |
| `0`          | 跳到当前行开头                               |
| `$`          | 跳到当前行结尾                               |
| `gg`         | 跳到文件第一行                               |
| `G`          | 跳到文件最后一行                             |
| `:行号` 回车 | 直接跳转到指定行（比如 `:100` 跳第100行）    |

## 3. 命令模式 - 编辑操作
| 按键       | 作用                   |
| ---------- | ---------------------- |
| `u`        | 撤销上一步（最常用）   |
| `Ctrl + r` | 重做（恢复撤销）       |
| `dd`       | 删除（剪切）当前整行   |
| `yy`       | 复制当前整行           |
| `p`        | 粘贴到光标下一行       |
| `x`        | 删除光标所在的单个字符 |

## 4. 末行模式 - 保存与退出
| 命令   | 作用                             |
| ------ | -------------------------------- |
| `:w`   | 保存文件，不退出                 |
| `:q`   | 退出（文件没修改才能退）         |
| `:wq`  | 保存并退出                       |
| `:q!`  | 强制退出，不保存修改             |
| `:wq!` | 强制保存并退出（权限不足时常用） |

## 5. 命令模式 - 搜索定位（改配置最常用）
| 命令           | 作用                 |
| -------------- | -------------------- |
| `/关键词` 回车 | 向下搜索关键词       |
| `n`            | 跳转到下一个匹配结果 |
| `N`            | 跳转到上一个匹配结果 |
