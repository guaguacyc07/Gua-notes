# C 语言速通

> 面向已有 Java / Python / Go 等语言基础、准备用 C 实现数据结构的人。
> 聚焦写数据结构真正会用到的 C：类型、指针、内存、结构体、宏、调试。
> 默认 C17，编译器 GCC / Clang；代码按 `-std=c17 -Wall -Wextra -Wpedantic` 编写。
> 示例为聚焦语法会省略部分 `#include` 和 `main`；完整容器实现见第 11 节。
> 主要容器代码已在 GCC 14 / C17 下编译运行通过。

**先建立三个认知**

1. C 的 `struct` 没有方法。数据用 `struct` 存，操作写成一组函数，靠命名前缀关联，例如 `vector_push`、`vector_free`。
2. C 没有垃圾回收。谁申请谁释放；容器必须明确自己是否“拥有”元素。
3. C 不检查数组越界，也不检查指针是否有效。越界、悬空、泄漏只能靠纪律和工具发现。

**和高级语言对照**

| 需求 | Java / Python | C |
| --- | --- | --- |
| 对象 | `class` | `struct` + 一组函数 |
| 实例方法里的 `this` | `this` / `self` | 显式传入的指针参数 |
| 创建对象 | `new` | `malloc` + 初始化函数 |
| 回收 | GC | `free`，手动管理 |
| 错误 | 异常 | 返回码 + 输出参数 |
| 字符串 | `String` / `str` | `char` 数组，以 `'\0'` 结尾 |
| 数组 | 带长度和边界检查 | 首地址 + 长度，自己检查 |
| 泛型 | 泛型 / 协议 | `void *` 或宏 |
| 命名空间 | `package` / `namespace` | 函数名前缀 |
| 布尔 | `boolean` / `bool` | `bool`（`<stdbool.h>`） |

## 1. 编译

C 的执行模型是：每个 `.c` 文件单独编译成 `.o`，最后链接成可执行文件。

```text
hello.c ──预处理──> hello.i ──编译──> hello.s ──汇编──> hello.o ──链接──> app
```

**声明与定义**

- 声明：告诉编译器“有这个类型 / 函数 / 变量”，不分配存储。
- 定义：真正分配存储，或给出函数体。
- 头文件放声明、类型、宏；`.c` 文件放定义。
- 一个函数只能定义一次；可以声明多次。

```c
/* vector.h */
#ifndef VECTOR_H
#define VECTOR_H

#include <stddef.h>

typedef struct {
    int *data;
    size_t size;
    size_t capacity;
} IntVector;

int vector_init(IntVector *v, size_t cap);
void vector_destroy(IntVector *v);
int vector_push(IntVector *v, int value);

#endif
```

```c
/* vector.c */
#include "vector.h"
#include <stdlib.h>

int vector_init(IntVector *v, size_t cap) {
    v->data = NULL;
    v->size = 0;
    v->capacity = 0;
    if (cap == 0) return 0;
    v->data = malloc(cap * sizeof *v->data);
    if (!v->data) return -1;
    v->capacity = cap;
    return 0;
}

void vector_destroy(IntVector *v) {
    free(v->data);
    v->data = NULL;
    v->size = 0;
    v->capacity = 0;
}
```

`#ifndef` / `#define` / `#endif` 叫头文件守卫，防止同一个头文件被重复包含。`#pragma once` 更短，但不是 C 标准，移植性略差；初学统一用守卫。

**static 和 extern**

- 文件作用域的 `static`：内部链接，只在本 `.c` 可见，用来隐藏辅助函数。
- 函数内的 `static`：静态存储期，函数返回后值还在，但作用域仍只在函数内。
- `extern`：声明“这个变量/函数在别处定义”。
- 头文件里写普通变量定义（如 `int count = 0;`）会被多个 `.c` 包含，链接时报 `multiple definition`。头文件里应写 `extern int count;`，在某个 `.c` 里定义。

**编译命令**

```bash
# 单个文件，练习时最常用
gcc -std=c17 -Wall -Wextra -Wpedantic -g -O0 main.c -o app

# 多文件
gcc -std=c17 -Wall -Wextra -Wpedantic -g -O0 main.c vector.c -o app

# 打开地址/未定义行为检查（调试内存问题非常有用）
gcc -std=c17 -g -O1 -fsanitize=address,undefined -fno-omit-frame-pointer main.c vector.c -o app
```

- `-g`：保留调试符号，给 gdb 用。
- `-O0`：关闭优化，调试时变量不会被优化掉。
- `-O2`：发布/性能测试用；未定义行为在优化后可能表现完全不同。
- `-Wall -Wextra`：打开常用警告，不要忽略。
- `-Wconversion -Wshadow -Wsign-conversion`：更严格，初学可以逐步加。
- Linux 上用 `<math.h>` 时要加 `-lm`。

**最小 Makefile**

```make
CC = gcc
CFLAGS = -std=c17 -Wall -Wextra -Wpedantic -g -O0
TARGET = app
OBJS = main.o vector.o

$(TARGET): $(OBJS)
	$(CC) $(CFLAGS) $^ -o $@

%.o: %.c
	$(CC) $(CFLAGS) -c $< -o $@

clean:
	rm -f $(OBJS) $(TARGET)
```

注意：Makefile 的命令行必须以 Tab 开头，不能用空格。

**常见编译错误**

| 报错 | 通常原因 |
| --- | --- |
| `undefined reference to ...` | 函数声明了但没定义，或 `.c` 没参与链接 |
| `multiple definition of ...` | 头文件里放了函数/变量定义，或没写头文件守卫 |
| `implicit declaration of function` | 没包含对应头文件，或函数名拼错 |
| `expected ';' before ...` | 结构体/函数声明末尾漏分号 |
| `assignment to expression with array type` | 数组不能整体赋值，用 `memcpy` 或逐元素复制 |
| `dereferencing pointer to incomplete type` | 只写了 `struct Foo;`，没看到完整定义 |

C 没有包和命名空间。多个模块的函数名要加前缀，例如 `list_`、`tree_`、`graph_`，否则很容易重名。

## 2. 类型

**基本类型**

| 类型 | 说明 | 常见用途 |
| --- | --- | --- |
| `char` | 1 字节，至少 8 位；是否有符号由实现决定 | 字符、字节 |
| `short` | 至少 16 位 | 很少用 |
| `int` | 至少 16 位，通常 32 位 | 普通整数、结点值 |
| `long` | 至少 32 位；Windows 32 位，Linux 64 位 | 不要假设宽度 |
| `long long` | 至少 64 位 | 大整数 |
| `float` / `double` | 浮点数 | 权值、坐标 |
| `size_t` | 无符号，`sizeof` 的返回类型 | 数组长度、容量、下标 |
| `ptrdiff_t` | 有符号，指针相减的结果 | 指针距离 |
| `bool` | `<stdbool.h>`，C23 起是关键字 | 条件、标志 |

需要精确宽度时用 `<stdint.h>`：

```c
#include <stdint.h>

int32_t a = 42;
uint64_t b = 42ull;
int8_t c = -1;
uintptr_t addr = (uintptr_t)&a;   /* 指针转整数，做地址运算/打印 */
```

**sizeof 和宽度**

```c
#include <stdio.h>

int main(void) {
    printf("char=%zu int=%zu long=%zu pointer=%zu\n",
           sizeof(char), sizeof(int), sizeof(long), sizeof(void *));
    return 0;
}
```

- `sizeof(char) == 1` 是标准保证的，但一个字节不一定是 8 位，位数看 `CHAR_BIT`。
- `sizeof` 的结果类型是 `size_t`，打印用 `%zu`。
- `sizeof` 是编译期运算符，不会求值操作数（VLA 除外）：

```c
int i = 0;
size_t s = sizeof(i++);   /* i 仍然是 0 */
```

**整数转换的坑**

C 的整数运算会自动做“常用算术转换”，有符号和无符号混用很容易出错。

```c
unsigned int u = 1;
int i = -2;
if (i < u) {
    /* 不会进入：i 被转换成 unsigned，-2 变成很大的正数 */
}

int n = -1;
if (n < sizeof(int)) {
    /* 不会进入：sizeof 是 size_t，n 被转换成无符号数 */
}
```

倒序遍历时尤其危险：

```c
size_t n = 0;
for (size_t i = n - 1; i >= 0; --i) {
    /* n 为 0 时，n - 1 回绕成 SIZE_MAX，条件永远成立 */
}
```

正确写法之一：

```c
for (size_t i = n; i-- > 0; ) {
    /* i 依次是 n-1, n-2, ..., 0 */
}
```

**有符号溢出是未定义行为**

```c
int x = INT_MAX;
x + 1;              /* 未定义行为，不是“变成最小负数” */

unsigned y = UINT_MAX;
y + 1;              /* 定义为 0，无符号数按 2^N 取模 */
```

无符号回绕是合法的，有符号溢出不是。不要依赖有符号溢出的结果。

**除法与取模**

C99 起，整数除法向零截断：

```c
-7 / 2   /* -3 */
-7 % 2   /* -1 */
 7 / -2  /* -3 */
 7 % -2  /*  1 */
```

取模结果的符号跟被除数（左边的数）一致。做哈希时如果要非负结果，先转成无符号，或加一个模数再取模。

**位运算与标志位**

```c
enum {
    FLAG_VISITED = 1u << 0,
    FLAG_QUEUED  = 1u << 1,
    FLAG_DONE    = 1u << 2
};

unsigned flags = 0;
flags |= FLAG_VISITED;          /* 置位 */
if (flags & FLAG_VISITED) {     /* 判断 */
    flags &= ~FLAG_VISITED;     /* 清位 */
}
```

- `&` 是按位与，`&&` 是逻辑与；不要混。
- 左移位数不能大于等于类型宽度；左移负数是有符号溢出，未定义。
- `1 << 31` 对 32 位 `int` 是未定义行为；用 `1u << 31`。

**bool**

```c
#include <stdbool.h>

bool ok = true;
if (!ok) {
    /* ... */
}
```

C 的 `if` / `while` 条件只要求“非零为真”，不要求一定是 `bool`。指针、整数都能直接当条件，但为了可读性，比较时写清楚：

```c
if (p != NULL) { ... }
if (count > 0) { ... }
```

**const**

```c
const int x = 10;
/* x = 20; 编译错误 */

const int *p = &x;        /* 指向的内容不能通过 p 改 */

int y = 10;
int *const q = &y;        /* 指针本身不能改，但 *q 可改 */
```

在 C 里，`const` 变量不一定是“编译期常量”。数组长度需要整数常量表达式：

```c
const int n = 10;
int a[n];          /* C99 的变长数组 VLA，不是固定长度数组 */

enum { N = 10 };
int b[N];          /* 真正的固定长度数组 */
```

**typedef**

```c
typedef unsigned long long u64;
typedef struct Node Node;

struct Node {
    int value;
    Node *next;     /* 这里可以直接用 Node，因为上面已经 typedef */
};
```

`typedef` 是类型别名，不是新类型；`#define` 是文本替换，二者不要混用。

**枚举**

```c
typedef enum {
    DS_OK = 0,
    DS_ERR_INVAL = -1,
    DS_ERR_NOMEM = -2,
    DS_ERR_EMPTY = -3
} DsStatus;
```

枚举本质上是整型，适合状态码、选项、标志。不要依赖枚举的具体底层类型做二进制序列化。

**字符常量和字符串字面量**

```c
char c = 'A';           /* 在 C 中 'A' 的类型是 int */
char s[] = "ABC";       /* 数组内容：'A','B','C','\0' */
size_t n = sizeof("ABC");  /* 4，包含结尾的 '\0' */
```

`'A'` 和 `"A"` 不是一回事：前者是整数，后者是字符串字面量（数组）。在 C 里 `sizeof('A')` 通常等于 `sizeof(int)`，这点和 C++ 不同。

**类型选择的实用建议**

- 结点里存的元素：先用 `int`，需要泛型再考虑 `void *`。
- 下标、长度、容量：统一用 `size_t`。
- 需要返回“失败/成功”：用 `int` 或自定义 `enum`，别用 `bool` 丢掉错误原因。
- 指针差值：用 `ptrdiff_t`，打印用 `%td`。
- 要存指针地址做调试：用 `uintptr_t` 或直接 `%p`。
- 不要用 `float` 做精确计数或哈希键；浮点比较用容差。

## 3. 指针

指针就是内存地址。理解下面这张图，后面所有链表、树、图都是它的组合。

```text
int a = 42;
int *p = &a;

变量 a：地址 0x1000，内容 42
变量 p：地址 0x2000，内容 0x1000  ──指向──> a
```

```c
int a = 42;
int *p = &a;      /* & 取地址 */
printf("%d\n", *p);  /* * 解引用，输出 42 */
*p = 7;           /* 通过指针修改 a */
```

`*` 在声明里表示“指针类型”，在表达式里表示“解引用”，两者含义不同。

**声明陷阱**

```c
int *p, q;        /* p 是 int*，q 是 int，不是两个指针 */
```

一行声明多个指针时，每个变量前都要写 `*`，或者干脆一行一个。

**空指针**

```c
int *p = NULL;
if (p != NULL) {
    *p = 1;       /* 解引用空指针是未定义行为，通常直接崩溃 */
}
```

`NULL` 是空指针常量，定义在 `<stddef.h>`、`<stdio.h>` 等头文件里。不要用 `0` 或 `'\0'` 代替指针语境下的 `NULL`，可读性差。

**指针运算**

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;             /* 等价于 &a[0] */

printf("%d\n", *(p + 2));  /* 30 */
printf("%d\n", p[2]);      /* 30，p[i] 等价于 *(p + i) */
p++;                       /* 前进 sizeof(int) 字节，不是 1 字节 */
```

- 指针加减的单位是“它指向的类型的大小”。
- 只有指向同一个数组（或尾后位置）的指针才能相减、做大小比较；任意对象指针之间可以用 `==`/`!=` 比较，但只有指向同一地址或都为 `NULL` 时才保证相等。
- `a + 5` 是合法的“尾后指针”，可以参与同一数组内的比较，但不能解引用。
- 越界指针运算本身可能就是未定义行为。

**数组退化为指针**

```c
void fill(int a[], size_t n);   /* 参数实际上是指针 int *a */
void fill(int *a, size_t n);    /* 与上面完全等价 */
```

数组作为函数参数时，长度信息丢失，必须额外传 `n`：

```c
void fill(int *a, size_t n) {
    for (size_t i = 0; i < n; ++i) {
        a[i] = 0;
    }
}
```

在数组定义所在的函数里，`sizeof` 还能得到整个数组大小：

```c
int a[10];
size_t n = sizeof a / sizeof a[0];   /* 10 */
```

把 `a` 传进函数后，`sizeof a` 就变成指针大小了。

**const 和指针**

从右往左读：

```c
const int *p;        /* p 指向 const int：不能通过 p 改内容 */
int *const p = &a;   /* p 是 const 指针：不能改 p 的指向 */
const int *const p = &a;  /* 两者都不能改 */
```

常见 API 写法：

```c
size_t vector_size(const IntVector *v);  /* 不修改容器 */
int vector_push(IntVector *v, int value);/* 可能修改容器 */
```

**多级指针**

```c
int x = 1;
int *p = &x;
int **pp = &p;

**pp = 2;      /* x 变成 2 */
```

链表头插、删除头结点时，用 `Node **` 可以直接修改调用者的头指针：

```c
int list_push_front(Node **head, int value) {
    Node *node = malloc(sizeof *node);
    if (!node) return -1;
    node->value = value;
    node->next = *head;
    *head = node;
    return 0;
}
```

**函数指针**

函数名本身可以当作函数地址。函数指针常用于比较器、回调、遍历策略。

```c
#include <stddef.h>

typedef int (*Comparator)(const void *a, const void *b);

int cmp_int(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);   /* 不会像 x - y 那样溢出 */
}

Comparator cmp = cmp_int;
```

`qsort` 的最后一个参数就是这种函数指针：

```c
int a[] = {3, 1, 2};
qsort(a, 3, sizeof a[0], cmp_int);
```

**void 指针**

`void *` 是“无类型指针”，可以接收任何对象指针，也可以隐式转回对象指针（C 允许，C++ 需要显式转换）。

```c
void *raw = malloc(10 * sizeof(int));
int *p = raw;
p[0] = 1;
free(raw);
```

- `void *` 不能直接解引用，也不能直接做指针算术（GCC 允许 `void *` 加减，但那是扩展）。
- `malloc` 返回 `void *`，C 里不需要写 `(int *)malloc(...)`。
- 函数指针转 `void *` 不保证可移植，不要这么干。

**二维数组和指针**

```c
int m[3][4];
int (*row)[4] = m;      /* row 是指向“含 4 个 int 的数组”的指针 */
row[1][2] = 5;

void print(int (*a)[4], int rows) {
    for (int i = 0; i < rows; ++i) {
        for (int j = 0; j < 4; ++j) {
            printf("%d ", a[i][j]);
        }
    }
}
```

区分：

```c
int *a[4];       /* 数组，含 4 个 int* */
int (*b)[4];     /* 指针，指向含 4 个 int 的数组 */
```

**指针与字符串**

```c
char s[] = "abc";     /* 可写的字符数组 */
char *p = "abc";      /* 指向字符串字面量，通常只读，不要改 */
```

修改字符串字面量是未定义行为，可能直接崩溃。

**常见指针错误**

- 未初始化就解引用：`int *p; *p = 1;`
- 返回局部变量的地址：函数结束后栈帧失效。
- 释放后继续用：`free(p); p->next = ...;`
- 释放后再次释放：double free。
- 越界访问：`a[n]`、`p[n]`。
- 指针层级搞错：该用 `Node **` 的地方用了 `Node *`。
- 把 `sizeof(pointer)` 当成数组长度。
- 指针类型不匹配，强制转换后访问导致对齐或别名问题。

调试时可以打印地址：

```c
printf("p=%p\n", (void *)p);
```

`%p` 要求参数是 `void *`，其他指针类型要显式转换。

## 4. 内存

**进程内存布局（典型情况，具体顺序由实现决定）**

```text
高地址
┌──────────────────────────┐
│ 栈 stack                 │  局部变量、函数调用信息，向低地址增长
├──────────────────────────┤
│          ...             │
├──────────────────────────┤
│ 堆 heap                  │  malloc / calloc / realloc，向高地址增长
├──────────────────────────┤
│ BSS                      │  未初始化的全局/静态变量，启动时清零
├──────────────────────────┤
│ 数据段 data              │  已初始化的全局/静态变量
├──────────────────────────┤
│ 只读数据 rodata          │  字符串字面量、const 全局数据
├──────────────────────────┤
│ 代码段 text              │  机器指令
└──────────────────────────┘
低地址
```

**存储期**

| 存储期 | 例子 | 生命周期 | 初始值 |
| --- | --- | --- | --- |
| 自动 | 函数内局部变量 | 进入块到离开块 | 未初始化 |
| 静态 | 全局变量、`static` 局部/全局 | 整个程序 | 零初始化 |
| 动态 | `malloc` 得到的对象 | 到 `free` 为止 | 未初始化（`calloc` 为零） |

**栈**

- 函数参数、局部变量、返回地址通常放在栈上。
- 自动分配、自动回收，速度快。
- 空间有限，递归太深或局部数组太大会栈溢出。
- 不要返回指向局部变量的指针：

```c
int *bad(void) {
    int x = 42;
    return &x;      /* 函数返回后 x 的栈空间失效 */
}
```

需要返回长期存在的对象时，用 `malloc`，或让调用者传入缓冲区。

**静态存储**

```c
int global_count;          /* 零初始化，整个程序有效 */
static int file_count;     /* 本文件可见，零初始化 */

void f(void) {
    static int calls;      /* 只初始化一次，函数返回后保留 */
    ++calls;
}
```

`static` 局部变量不是线程安全的；多线程下要加锁或用原子操作。

**堆**

| 函数 | 作用 | 初始化 | 失败返回 |
| --- | --- | --- | --- |
| `malloc(n)` | 分配 `n` 字节 | 不初始化 | `NULL` |
| `calloc(n, size)` | 分配 `n * size` 字节 | 全部字节清零 | `NULL` |
| `realloc(p, n)` | 调整已分配块大小 | 新区域不初始化 | `NULL`，原块保留 |
| `free(p)` | 释放 | — | — |

基本模板：

```c
#include <stdlib.h>

int *p = malloc(n * sizeof *p);
if (p == NULL) {
    /* 处理分配失败 */
    return -1;
}

/* 使用 p ... */

free(p);
p = NULL;      /* 防止后续误用；不是必须，但推荐 */
```

`sizeof *p` 比 `sizeof(int)` 更稳：改变 `p` 的类型时不用改分配代码。

**realloc 的正确写法**

```c
int *tmp = realloc(v->data, new_capacity * sizeof *tmp);
if (tmp == NULL) {
    /* 分配失败，v->data 仍然有效，不要直接覆盖 */
    return -1;
}
v->data = tmp;
v->capacity = new_capacity;
```

不要写：

```c
v->data = realloc(v->data, new_capacity * sizeof *v->data);
if (v->data == NULL) { /* 原指针已经丢了，内存泄漏 */ }
```

**分配大小溢出**

`n * sizeof *p` 可能溢出 `size_t`，算出一个小值，然后越界写。

```c
#include <stdint.h>

if (n > SIZE_MAX / sizeof *p) {
    return NULL;
}
int *p = malloc(n * sizeof *p);
```

`calloc(n, size)` 通常也会检查乘法溢出，但不同实现不完全一样；安全关键代码自己检查。

**malloc 的细节**

- `malloc(0)` 可能返回 `NULL`，也可能返回一个不能解引用的唯一指针；不要依赖。
- `free(NULL)` 是合法的，什么也不做。
- `free` 不会把指针置空，释放后原指针变成悬空指针。
- `realloc(p, 0)` 的行为在标准里有争议/实现相关，避免使用；要释放就 `free(p)`。
- 同一个块不能释放两次；不能释放栈地址或数组中间元素的地址。
- `malloc` 返回的指针对任何类型都满足基本对齐要求（`max_align_t`）。

**所有权**

每个动态对象都要有明确的“所有者”。容器 API 要写清楚：

- 容器只保存指针，不负责释放元素：调用者负责。
- 容器拥有元素，`destroy` 时逐个释放：容器负责。
- 转移所有权：插入后调用者不要再释放。

链表、树、图最容易出现“结点释放了，但里面的字符串没释放”的半泄漏。写 `destroy` 时按“先释放成员，再释放结点”的顺序。

**结构体对齐与填充**

```c
#include <stdio.h>
#include <stddef.h>

struct A {
    char c;
    int i;
    char d;
};

struct B {
    int i;
    char c;
    char d;
};

int main(void) {
    printf("A=%zu B=%zu offset_i=%zu\n",
           sizeof(struct A), sizeof(struct B),
           offsetof(struct B, i));
    return 0;
}
```

在常见的 4 字节 `int` 平台上，`struct A` 通常是 12 字节，`struct B` 通常是 8 字节。编译器会在成员之间插入填充字节，让每个成员满足对齐要求。

- 用 `sizeof` 算大小，不要手算。
- 用 `offsetof(type, member)` 取成员偏移，需要 `<stddef.h>`。
- 调整成员顺序可以减小结构体，但不要为了省几字节牺牲可读性。
- `#pragma pack` 会改变对齐，可能降低性能，且不是标准；只有解析二进制协议时才考虑。

**柔性数组**

结构体最后一个成员可以写成不指定长度的数组：

```c
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct {
    size_t len;
    int data[];
} IntArray;

IntArray *int_array_new(size_t n) {
    if (n > (SIZE_MAX - sizeof(IntArray)) / sizeof(int)) {
        return NULL;
    }
    IntArray *a = malloc(sizeof *a + n * sizeof a->data[0]);
    if (!a) return NULL;
    a->len = n;
    return a;
}
```

- `data[]` 不占 `sizeof(IntArray)` 的空间，但必须放在最后。
- 分配时用 `sizeof *a + n * sizeof a->data[0]`。
- 适合“头部固定 + 后面跟变长数据”的结构，比如字符串、邻接表边数组。

**浅拷贝与深拷贝**

```c
typedef struct {
    char *name;
    int age;
} Person;

Person a = { .name = "Tom", .age = 18 };
Person b = a;          /* 浅拷贝：b.name 和 a.name 指向同一块内存 */
```

如果 `name` 是 `malloc` 出来的，`b = a` 后两个结构体指向同一块内存，释放两次就崩。需要深拷贝：

```c
#include <string.h>

Person person_clone(const Person *src) {
    Person dst = *src;
    if (src->name) {
        size_t n = strlen(src->name) + 1;
        dst.name = malloc(n);
        if (dst.name) {
            memcpy(dst.name, src->name, n);
        }
    }
    return dst;
}
```

结构体赋值会复制数组成员，但指针成员只复制地址。

**memcpy、memmove、memset、memcmp**

```c
#include <string.h>

int a[5] = {1, 2, 3, 4, 5};
int b[5];

memcpy(b, a, sizeof a);          /* 不重叠的内存复制 */
memmove(b, b + 1, 3 * sizeof b[0]); /* 允许重叠 */
memset(b, 0, sizeof b);          /* 按字节填充，通常用来清零整数数组 */

if (memcmp(a, b, sizeof a) == 0) {
    /* 逐字节相等 */
}
```

- `memcpy` 的源和目标重叠时行为未定义，用 `memmove`。
- `memset` 按字节写，不是按元素写；把 `int` 数组的每个字节设成 `0xff`，在补码平台上得到 `-1`，但这不是可移植的按元素初始化方式。
- 含指针的结构体不要随便 `memset` 成 0；空指针不保证所有位都是 0。
- 结构体不要用 `memcmp` 比较：填充字节的值是不确定的，可能两个字段完全相同的结构体比较结果不相等。

**内存问题四件套**

| 问题 | 表现 | 工具 |
| --- | --- | --- |
| 越界写 | 破坏相邻数据、随机崩溃 | ASan、gdb |
| 释放后使用 | 读到垃圾、崩溃 | ASan |
| 双重释放 | 堆管理器报错、崩溃 | ASan、Valgrind |
| 泄漏 | 程序越跑内存越大 | ASan/LeakSanitizer、Valgrind |

**栈还是堆**

- 小规模、生命周期明确、大小固定：栈。
- 大小运行时才知道、需要跨函数存活、可能很大：堆。
- 链表/树的结点通常逐个 `malloc`；数据量很大时，逐个分配的开销和碎片会很明显的，可以考虑内存池。
- 数组/动态数组的连续内存对缓存友好，通常比链表快，即使理论复杂度相同。

**内存池（了解）**

频繁 `malloc/free` 小结点时，可以一次申请一大块，再切成固定大小的结点；释放时把结点挂回空闲链表，最后整块释放。优点是分配快、碎片少；缺点是要自己管理块的生命周期。初学数据结构先用 `malloc/free`，把正确性跑通再说。

## 5. 函数

**声明、定义、调用**

```c
/* 声明（原型）：告诉编译器参数和返回类型 */
int add(int a, int b);

/* 定义：给出函数体 */
int add(int a, int b) {
    return a + b;
}

int main(void) {
    int x = add(1, 2);
    return x == 3 ? 0 : 1;
}
```

- 函数必须先声明后使用；把声明放头文件，定义放 `.c`。
- `void f(void)` 表示“没有参数”；`void f()` 在 C 里表示“参数未指定”，不要这么写。
- 返回类型不是 `void` 的函数，所有路径都要有返回值；`main` 可以省略 `return 0`（C99 起默认返回 0），但建议写清楚。
- 参数和返回值按值传递，结构体也一样，会复制整个结构体。

**值传递**

```c
void bad_swap(int a, int b) {
    int t = a;
    a = b;
    b = t;          /* 只交换了副本，调用者看不到 */
}

void good_swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}
```

要在函数里修改调用者的变量，必须传地址。要修改指针本身（比如链表头指针），就传指针的地址，即 `Node **`。

**数组参数**

```c
void fill(int *a, size_t n) {
    for (size_t i = 0; i < n; ++i) {
        a[i] = 0;
    }
}

int a[10];
fill(a, 10);       /* 数组名退化为首元素地址 */
```

函数内部拿不到数组长度，必须显式传 `n`。不要用 `sizeof a / sizeof a[0]` 去算函数参数的长度，那得到的是指针大小。

**返回值**

- 返回标量、结构体：直接按值返回，调用者得到副本。
- 返回指针：必须保证指向的对象在函数返回后仍然有效。
- 不要返回局部数组或局部变量的地址。
- 返回 `malloc` 的指针时，调用者要负责 `free`，并在接口注释里写清楚。
- 返回多个值：用结构体，或让调用者传输出参数。

```c
typedef struct {
    int ok;
    int value;
} Result;

Result divide(int a, int b) {
    if (b == 0) return (Result){ .ok = 0, .value = 0 };
    return (Result){ .ok = 1, .value = a / b };
}
```

**输出参数**

```c
int vector_pop(IntVector *v, int *out) {
    if (!v || v->size == 0) return -1;
    v->size--;
    if (out) *out = v->data[v->size];
    return 0;
}
```

约定：返回值表示成功/失败，`out` 只在成功时写入。调用者要先检查返回值，再读 `out`。

**递归**

递归三要素：

1. 终止条件。
2. 规模缩小。
3. 每层只处理当前层。

```c
long factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

void hanoi(int n, char from, char to, char via) {
    if (n == 0) return;
    hanoi(n - 1, from, via, to);
    printf("%c -> %c\n", from, to);
    hanoi(n - 1, via, to, from);
}
```

递归的代价是调用栈。`factorial(100000)` 很可能栈溢出。阶乘增长很快，`n` 稍大就会溢出，这里只演示递归结构。树的中序遍历、图的 DFS 用递归很自然，但退化树或大图可能深度达到 `O(n)`，要改成显式栈。

尾递归在 C 里不保证优化；不要为了“尾递归”牺牲可读性，深度大就用迭代。

**函数指针和回调**

```c
typedef int (*CompareFn)(const void *a, const void *b);

void sort_ints(int *a, size_t n, CompareFn cmp) {
    qsort(a, n, sizeof a[0], cmp);
}
```

回调让容器/算法与具体类型解耦。写回调时注意：

- 参数类型必须是 `const void *`（如果不想修改元素）。
- 返回值负数/0/正数表示小于/等于/大于。
- 不要用 `a - b` 直接返回，可能溢出。
- 回调里不要修改正在被排序的数组。

**static 函数**

```c
static int max_int(int a, int b) {
    return a > b ? a : b;
}
```

`static` 函数只在当前 `.c` 可见，适合内部辅助函数。头文件里不要放普通函数定义；需要跨文件共享就放声明，定义放一个 `.c`。

**inline**

```c
static inline int max_int(int a, int b) {
    return a > b ? a : b;
}
```

`static inline` 可以放在头文件里，允许多个编译单元各有一份，通常用于短小、频繁调用的函数。`inline` 的标准语义比较绕，初学直接用 `static inline` 或普通函数。

**main 函数**

```c
#include <stdio.h>

int main(int argc, char **argv) {
    if (argc < 2) {
        fprintf(stderr, "usage: %s <file>\n", argv[0]);
        return 1;
    }
    printf("file = %s\n", argv[1]);
    return 0;
}
```

- `argc` 是参数个数，包含程序名。
- `argv[0]` 是程序名，`argv[argc]` 是 `NULL`。
- 返回 0 表示成功，非 0 表示失败；脚本/CI 会检查这个值。

**可变参数（了解）**

```c
#include <stdarg.h>

int sum(int count, ...) {
    va_list ap;
    va_start(ap, count);
    int total = 0;
    for (int i = 0; i < count; ++i) {
        total += va_arg(ap, int);
    }
    va_end(ap);
    return total;
}
```

可变参数没有类型检查，调用者必须保证类型和个数正确。数据结构代码里很少需要，优先用数组 + 长度。

**命名**

C 没有重载，同一作用域不能有两个同名函数。用模块前缀避免冲突：

```c
vector_init
vector_destroy
vector_push
vector_pop
vector_get
vector_size
```

**递归改迭代的常见方式**

- 用显式栈保存待处理结点（树、图 DFS）。
- 用队列保存待处理结点（图 BFS）。
- 用循环 + 前驱/后继指针（链表反转、遍历）。
- 用状态机（括号匹配、表达式求值）。

## 6. 结构体

**定义与 typedef**

```c
typedef struct Node {
    int value;
    struct Node *next;
} Node;
```

- `struct Node` 是结构体标签，`Node` 是 `typedef` 别名。
- 结构体内部自引用必须用标签名 `struct Node *`，因为此时 `Node` 这个别名还没定义完。
- 也可以先 `typedef struct Node Node;`，再定义 `struct Node { Node *next; };`。

**初始化**

```c
Node a = { .value = 1, .next = NULL };       /* 指定初始化器，C99 */
Node b = { 1, NULL };                        /* 按成员顺序 */
Node *p = &(Node){ .value = 2, .next = NULL }; /* 复合字面量，块作用域内有效 */
```

指定初始化器可读性更好，字段顺序变化时不容易错。未显式初始化的成员会被零初始化（聚合初始化时）；局部变量如果不初始化，内容是随机的。

**赋值是浅拷贝**

```c
Node a = { .value = 1, .next = NULL };
Node b = a;          /* 复制 value 和 next 指针 */
```

- 结构体赋值会复制所有成员，包括数组。
- 指针成员只复制地址，不会复制指向的对象。
- 两个结构体指向同一块堆内存时，释放两次会崩。

**结构体作为参数和返回值**

```c
void print_node(Node n);          /* 复制整个结构体，适合小结构体 */
void update_node(Node *n);        /* 传地址，避免复制，允许修改 */
Node make_node(int value);        /* 返回结构体，按值复制 */
```

大结构体优先传 `const Node *`，避免复制。小结构体（几个机器字）按值传也完全可以。

**结构体数组**

```c
Node nodes[10];
nodes[0].value = 1;
nodes[0].next = NULL;

Node *p = &nodes[0];
p->value = 2;       /* p->value 等价于 (*p).value */
```

**匿名结构体和联合体（C11）**

```c
typedef struct {
    int x;
    int y;
} Point;

typedef struct {
    Point pos;
    union {
        int id;
        char *name;
    };
} Entity;
```

匿名成员可以直接 `e.id` 访问。初学不建议滥用，明确命名更清楚。

**联合体**

```c
typedef union {
    int i;
    float f;
    unsigned char bytes[4];
} Value;
```

联合体的所有成员共享同一块内存，大小等于最大成员。同一时间只应使用一个成员；通过另一个成员读取，结果依赖实现，除非用 `memcpy` 做字节复制。

**标签联合（tagged union）**

```c
typedef enum {
    VALUE_INT,
    VALUE_DOUBLE
} ValueKind;

typedef struct {
    ValueKind kind;
    union {
        int i;
        double d;
    } as;
} Value;

void print_value(const Value *v) {
    switch (v->kind) {
        case VALUE_INT:
            printf("%d\n", v->as.i);
            break;
        case VALUE_DOUBLE:
            printf("%f\n", v->as.d);
            break;
    }
}
```

用一个 `kind` 字段记录当前联合体里哪个成员有效，这是 C 里实现“多态值”的常用方式。

**枚举**

```c
typedef enum {
    COLOR_RED,
    COLOR_GREEN,
    COLOR_BLUE
} Color;
```

枚举值默认从 0 开始递增。可以显式赋值，也可以用来做状态码：

```c
typedef enum {
    OK = 0,
    ERR_INVAL = -1,
    ERR_NOMEM = -2
} Status;
```

不要把枚举当字符串用；打印时用 `switch` 转成名字，或者单独维护名字表。

**不透明类型（ADT）**

头文件只暴露类型名和函数，结构体定义藏在 `.c` 里：

```c
/* vector.h */
#ifndef VECTOR_H
#define VECTOR_H

#include <stddef.h>

typedef struct Vector Vector;

Vector *vector_create(size_t cap);
void vector_destroy(Vector *v);
int vector_push(Vector *v, int value);
int vector_pop(Vector *v, int *out);
size_t vector_size(const Vector *v);

#endif
```

```c
/* vector.c */
#include "vector.h"
#include <stdint.h>
#include <stdlib.h>

struct Vector {
    int *data;
    size_t size;
    size_t capacity;
};

Vector *vector_create(size_t cap) {
    Vector *v = malloc(sizeof *v);
    if (!v) return NULL;
    v->data = NULL;
    v->size = 0;
    v->capacity = 0;
    if (cap > 0) {
        if (cap > SIZE_MAX / sizeof *v->data) {
            free(v);
            return NULL;
        }
        v->data = malloc(cap * sizeof *v->data);
        if (!v->data) {
            free(v);
            return NULL;
        }
        v->capacity = cap;
    }
    return v;
}

void vector_destroy(Vector *v) {
    if (!v) return;
    free(v->data);
    free(v);
}
```

优点：

- 调用者不能直接改内部字段，容器能维持不变量。
- 修改内部表示时不用改调用者代码。
- 头文件更干净，编译依赖更少。

缺点：

- 调用者不能把容器放在栈上，必须用 `create/destroy`。
- 每次访问要函数调用，可能有一点开销。
- 调试时看不到内部字段，需要额外的调试函数。

学习数据结构时，可以先暴露 `struct` 方便观察；写完整项目时再改成不透明类型。

**API 设计约定**

一个容器至少要有：

```c
Vector *vector_create(size_t cap);          /* 创建 */
void vector_destroy(Vector *v);             /* 销毁，允许传 NULL */
int vector_push(Vector *v, int value);      /* 修改，返回 0 成功 */
int vector_pop(Vector *v, int *out);        /* 修改，输出参数 */
int vector_get(const Vector *v, size_t i, int *out); /* 只读 */
size_t vector_size(const Vector *v);        /* 只读 */
bool vector_empty(const Vector *v);         /* 只读 */
```

约定：

- `create` 失败返回 `NULL`。
- `destroy(NULL)` 安全，什么都不做。
- 修改操作返回 `0` 成功、负数失败。
- 只读操作参数用 `const`。
- 下标越界返回错误，不直接崩溃（除非是内部断言）。
- `size` 和 `capacity` 满足 `size <= capacity`。
- `capacity > 0` 时 `data != NULL`。

**不变量**

不变量是“任何时候都必须成立的条件”。例如动态数组：

```text
size <= capacity
capacity == 0 或 data != NULL
data[0..size-1] 是有效元素
data[size..capacity-1] 是未使用空间
```

每次修改后检查不变量，能提前发现 bug：

```c
#include <assert.h>

static bool vector_invariant(const Vector *v) {
    if (!v) return false;
    if (v->size > v->capacity) return false;
    if (v->capacity > 0 && v->data == NULL) return false;
    return true;
}
```

在 `push`、`pop`、`reserve` 末尾 `assert(vector_invariant(v));`。断言只在调试时生效，发布时用 `-DNDEBUG` 去掉。

**泛型容器**

C 没有模板。两种常见做法：

1. `void *` + 元素大小，运行时复制字节。
2. 宏生成类型专用代码（类型安全，但代码膨胀、调试困难）。

`void *` 版本：

```c
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    unsigned char *data;
    size_t elem_size;
    size_t size;
    size_t capacity;
} Vector;

int vector_init(Vector *v, size_t elem_size) {
    if (!v || elem_size == 0) return -1;
    v->data = NULL;
    v->elem_size = elem_size;
    v->size = 0;
    v->capacity = 0;
    return 0;
}

void vector_destroy(Vector *v) {
    if (!v) return;
    free(v->data);
    v->data = NULL;
    v->size = 0;
    v->capacity = 0;
    v->elem_size = 0;
}

int vector_push(Vector *v, const void *elem) {
    if (!v || !elem) return -1;
    if (v->size == v->capacity) {
        size_t new_cap = v->capacity ? v->capacity * 2 : 4;
        if (new_cap < v->capacity) return -1;
        if (new_cap > SIZE_MAX / v->elem_size) return -1;
        unsigned char *tmp = realloc(v->data, new_cap * v->elem_size);
        if (!tmp) return -1;
        v->data = tmp;
        v->capacity = new_cap;
    }
    memcpy(v->data + v->size * v->elem_size, elem, v->elem_size);
    v->size++;
    return 0;
}

void *vector_at(Vector *v, size_t i) {
    if (!v || i >= v->size) return NULL;
    return v->data + i * v->elem_size;
}
```

注意：

- `vector_at` 返回的指针在 `push` 触发扩容后失效。
- 容器只复制元素字节，不负责释放元素内部指针。
- 元素如果包含指针，需要额外的 `destroy` 回调。
- 类型安全由调用者保证；取出来要转回正确类型。

**侵入式链表（了解）**

把链表结点嵌入数据对象，而不是让容器额外分配结点：

```c
typedef struct ListNode {
    struct ListNode *next;
} ListNode;

typedef struct {
    int value;
    ListNode link;
} Item;
```

多个链表可以共用同一个数据对象，适合内核、LRU 缓存等场景。用 `offsetof` 从 `ListNode *` 反推出 `Item *`：

```c
#define container_of(ptr, type, member) \
    ((type *)((char *)(ptr) - offsetof(type, member)))
```

初学数据结构不必用侵入式链表，知道有这种写法即可。

**结构体比较**

不要用 `memcmp` 比较两个结构体：

```c
/* 不可靠：padding 字节的值不确定 */
if (memcmp(&a, &b, sizeof a) == 0) { ... }
```

逐字段比较：

```c
bool node_equal(const Node *a, const Node *b) {
    return a->value == b->value;  /* next 是否参与比较，看语义 */
}
```

**位域（了解）**

```c
struct Flags {
    unsigned visited : 1;
    unsigned queued  : 1;
    unsigned color   : 2;
};
```

位域可以节省空间，但布局、对齐、字节序都依赖实现，不适合网络协议或持久化格式。数据结构里通常直接用 `unsigned` 位掩码更可控。

## 7. 字符串

**C 字符串的本质**

C 没有字符串类型。字符串是“以 `'\0'` 结尾的 `char` 数组”：

```text
"abc" 的内存：'a' 'b' 'c' '\0'
```

```c
char s[] = "abc";       /* sizeof(s) == 4，strlen(s) == 3 */
```

- `strlen` 从开头数到第一个 `'\0'`，不包含 `'\0'`，时间复杂度 `O(n)`。
- `sizeof` 是数组/类型的大小，编译期就能算（VLA 除外）。
- 字符串里不能直接存 `'\0'`，否则后面的内容会被当成结尾。
- 处理二进制数据要用 `memcpy` / `fread`，不要用 `str*` 函数。

**字面量 vs 数组**

```c
char a[] = "abc";     /* 栈/静态区的可写副本 */
char *b = "abc";      /* 指向只读字符串字面量，不要改 */
const char *c = "abc";/* 明确表示只读，推荐 */
```

```c
a[0] = 'X';   /* 合法 */
b[0] = 'X';   /* 未定义行为，可能崩溃 */
```

**长度和容量**

```c
char buf[32];
size_t len = strlen(buf);       /* 要求 buf 已经以 '\0' 结尾 */
size_t cap = sizeof buf;        /* 32 */
```

`strlen` 不会检查缓冲区边界；如果字符串没有 `'\0'`，会一直往后读，越界。

**安全复制和拼接**

```c
#include <stdio.h>
#include <string.h>

char dst[16];
const char *src = "hello";

int n = snprintf(dst, sizeof dst, "%s", src);
if (n < 0) {
    /* 编码错误 */
} else if ((size_t)n >= sizeof dst) {
    /* 被截断：dst 仍然以 '\0' 结尾，但内容不完整 */
}
```

- `strcpy` 不检查目标容量，能不用就不用。
- `strncpy(dst, src, n)` 在 `src` 长度小于 `n` 时会把剩余字节补 `'\0'`；长度大于等于 `n` 时不会自动加 `'\0'`，容易出错。
- `snprintf` 返回“原本想写多少字符”，可以用来判断截断；它保证结果以 `'\0'` 结尾（只要 `size > 0`）。
- `strcat` 同样不安全；拼接用 `snprintf` 或先算好长度再 `memcpy`。

**输入**

```c
char line[256];

if (fgets(line, sizeof line, stdin) != NULL) {
    line[strcspn(line, "\n")] = '\0';  /* 去掉换行 */
    printf("input: %s\n", line);
}
```

- `fgets` 最多读 `size - 1` 个字符，自动加 `'\0'`；遇到换行或 EOF 停止。
- 如果一行超过缓冲区，剩下的字符会留在输入流里，下次读到；要处理超长行。
- `gets` 已从 C11 标准移除，永远不要用。
- `scanf("%s", buf)` 不限制长度，和 `gets` 一样危险；要用 `scanf("%31s", buf)` 并检查返回值。
- `scanf` 返回成功匹配的项数，必须检查：

```c
int x;
if (scanf("%d", &x) != 1) {
    fprintf(stderr, "not a number\n");
    return 1;
}
```

- `scanf` 读数字后会把换行留在输入流里，后面混用 `fgets` 时要注意先清掉。
- `getline`（POSIX）能自动扩容，但不是 C 标准；跨平台代码用 `fgets` 循环拼接，或自己封装。

**输出格式**

| 格式 | 类型 | 说明 |
| --- | --- | --- |
| `%d` | `int` | 有符号十进制 |
| `%u` | `unsigned` | 无符号十进制 |
| `%ld` | `long` | 长整型 |
| `%lld` | `long long` | 更长的整型 |
| `%zu` | `size_t` | `sizeof`、长度、容量 |
| `%td` | `ptrdiff_t` | 指针差值 |
| `%x` / `%X` | `unsigned` | 十六进制 |
| `%o` | `unsigned` | 八进制 |
| `%f` | `double` | 浮点，默认 6 位小数 |
| `%e` | `double` | 科学计数法 |
| `%c` | `int`（char 提升） | 单个字符 |
| `%s` | `char *` | 字符串，必须以 `'\0'` 结尾 |
| `%p` | `void *` | 指针地址 |
| `%%` | — | 百分号本身 |

```c
printf("size=%zu cap=%zu\n", v->size, v->capacity);
printf("node=%p value=%d\n", (void *)node, node->value);
```

- 格式符和参数类型不匹配是未定义行为，编译器通常会给警告。
- `%s` 传 `NULL` 是未定义行为，打印前先判断。
- `printf` 返回输出的字符数，失败返回负数；写文件/管道时最好检查。
- `<inttypes.h>` 提供 `PRId64`、`PRIu64` 等可移植格式宏：

```c
#include <inttypes.h>
int64_t x = 42;
printf("%" PRId64 "\n", x);
```

**常用字符串函数**

| 函数 | 作用 | 注意 |
| --- | --- | --- |
| `strlen(s)` | 求长度 | `O(n)`，不要在循环条件里反复调用 |
| `strcmp(a, b)` | 比较 | 返回 0 表示相等，不要写成 `if (strcmp(a,b))` 表示相等 |
| `strncmp(a, b, n)` | 比较前 n 个字符 | 适合比较前缀 |
| `strchr(s, c)` | 找字符 | 返回指针或 `NULL` |
| `strrchr(s, c)` | 从右找字符 | 常用于找路径分隔符 |
| `strstr(s, sub)` | 找子串 | 返回第一次出现的位置 |
| `strspn(s, accept)` | 开头连续匹配集合的长度 | 解析用 |
| `strcspn(s, reject)` | 开头连续不匹配集合的长度 | 去换行常用 |
| `strtok(s, delim)` | 分割字符串 | 会修改原串，不可重入 |
| `strtok_r(s, delim, &save)` | 可重入分割 | POSIX，不是 C 标准 |
| `strcpy` / `strcat` | 复制/拼接 | 不安全，避免 |
| `strncpy` | 限长复制 | 可能不补 `'\0'` |
| `snprintf` | 格式化到缓冲区 | 推荐 |

`strcmp` 的返回值不要假设一定是 `-1/0/1`，只保证负/零/正。

**strtok 的坑**

```c
char s[] = "a,b,c";       /* 必须是可写数组，不能是字符串字面量 */
char *save = NULL;
for (char *tok = strtok_r(s, ",", &save); tok; tok = strtok_r(NULL, ",", &save)) {
    printf("%s\n", tok);
}
```

`strtok` 会把分隔符改成 `'\0'`，并维护内部静态状态；嵌套分割或多线程会互相干扰。`strtok_r` 用调用者提供的 `save` 指针保存状态。

**strtol 解析整数**

```c
#include <errno.h>
#include <limits.h>
#include <stdlib.h>

int parse_int(const char *s, int *out) {
    char *end = NULL;
    errno = 0;
    long v = strtol(s, &end, 10);
    if (errno != 0 || end == s || *end != '\0') return -1;
    if (v < INT_MIN || v > INT_MAX) return -1;
    *out = (int)v;
    return 0;
}
```

- `end == s`：没有解析到任何数字。
- `*end != '\0'`：后面还有多余字符。
- `errno == ERANGE`：超出 `long` 范围。
- 转成 `int` 前还要检查 `INT_MIN..INT_MAX`。
- 不要用 `atoi` 做错误检查，它无法区分 `"0"` 和 `"abc"`。

**文件 I/O**

```c
#include <stdio.h>

int copy_file(const char *src, const char *dst) {
    FILE *in = fopen(src, "rb");
    if (!in) {
        perror(src);
        return -1;
    }

    FILE *out = fopen(dst, "wb");
    if (!out) {
        perror(dst);
        fclose(in);
        return -1;
    }

    unsigned char buf[4096];
    size_t n;
    int rc = 0;
    while ((n = fread(buf, 1, sizeof buf, in)) > 0) {
        if (fwrite(buf, 1, n, out) != n) {
            rc = -1;
            break;
        }
    }
    if (ferror(in)) rc = -1;

    if (fclose(out) != 0) rc = -1;
    if (fclose(in) != 0) rc = -1;
    return rc;
}
```

- 文本模式 `"r"` / `"w"` 在 Windows 上会做换行转换；要按原样读写字节用 `"rb"` / `"wb"`。
- `fread` 返回实际读到的元素个数，不要用 `feof` 提前判断文件结束；应该先读，再根据返回值判断。
- `fclose` 可能失败，尤其是写入时；重要数据要检查。
- 直接用 `fwrite(&struct, sizeof struct, 1, fp)` 写结构体不可移植：填充字节、字节序、类型宽度都可能不同。要持久化就逐字段序列化。

**字符串和 UTF-8**

C 的 `char` 是字节。UTF-8 编码的中文一个汉字通常占 3 字节：

```c
printf("%zu\n", strlen("中"));   /* 常见 UTF-8 环境下是 3，不是 1 */
```

- `strlen` 数的是字节数，不是字符数。
- 按下标 `s[i]` 访问的是字节，不是“第 i 个汉字”。
- 需要按字符处理时用专门的 Unicode 库，或自己按 UTF-8 规则解码。
- 数据结构里如果 key 是字符串，哈希和比较都按字节做即可，但要注意统一编码。

**字符串的所有权**

如果结构体保存 `char *`，必须明确：

- 是指向调用者的字符串（不拥有），还是自己 `malloc` 的副本（拥有）。
- `destroy` 时是否要 `free` 每个字符串。
- 修改字符串时是否需要重新分配。

复制字符串（C17 没有标准 `strdup`，下面是可移植写法）：

```c
char *string_dup(const char *s) {
    if (!s) return NULL;
    size_t n = strlen(s) + 1;
    char *p = malloc(n);
    if (p) memcpy(p, s, n);
    return p;
}
```

`strdup` 是 POSIX 函数，很多平台有，但不属于 C17 标准；用了就失去部分可移植性。

## 8. 宏

**预处理发生在编译之前**

宏是文本替换，不是函数调用。理解这一点，就能理解大部分宏的坑。

```c
#define PI 3.1415926
#define MAX_SIZE 100
```

- 宏没有类型检查。
- 宏没有作用域，从定义处到文件末尾（或 `#undef`）都有效。
- 宏名习惯全大写，和变量/函数区分。
- 简单的整数常量优先用 `enum` 或 `const`；宏适合条件编译、头文件守卫、少量泛型代码。

**带参数的宏**

```c
#define SQUARE(x) ((x) * (x))
```

必须给参数和整体加括号，否则：

```c
#define BAD_SQUARE(x) x * x
BAD_SQUARE(1 + 2)   /* 展开成 1 + 2 * 1 + 2，结果是 5，不是 9 */
```

即使加了括号，宏仍可能重复求值：

```c
#define MAX(a, b) ((a) > (b) ? (a) : (b))
int i = 0;
int m = MAX(i++, 10);   /* i++ 可能执行两次 */
```

有副作用、需要类型检查、需要调试符号时，用函数：

```c
static inline int max_int(int a, int b) {
    return a > b ? a : b;
}
```

**多语句宏**

```c
#define SWAP_INT(a, b) do { \
    int _tmp = (a);         \
    (a) = (b);              \
    (b) = _tmp;             \
} while (0)
```

用 `do { ... } while (0)` 包起来，保证宏在 `if/else` 里展开后仍然是一个语句：

```c
if (cond)
    SWAP_INT(x, y);
else
    ...
```

如果宏展开成多条语句且没有包起来，`else` 会配错。

**字符串化和连接**

```c
#define STR(x) #x
#define XSTR(x) STR(x)
#define CAT(a, b) a##b

STR(hello)       /* "hello" */
XSTR(__LINE__)   /* 先把 __LINE__ 展开，再转字符串 */
CAT(foo, bar)    /* foobar */
```

`#` 把参数变成字符串字面量，`##` 把两个记号粘成一个。`STR(__LINE__)` 得到的是字符串 `"__LINE__"`，要得到行号需要两层宏 `XSTR`。

**条件编译**

```c
#ifdef DEBUG
    printf("debug: size=%zu\n", v->size);
#endif

#if defined(_WIN32)
    /* Windows 专用代码 */
#elif defined(__linux__)
    /* Linux 专用代码 */
#else
    #error "unsupported platform"
#endif
```

- `#ifdef X` 等价于 `#if defined(X)`。
- `#if 0 ... #endif` 常用来临时屏蔽代码。
- `#error` 在编译期报错，适合检查平台/配置。
- 不要用宏改变关键字或类型，例如 `#define int long`，后患无穷。

**头文件守卫**

```c
#ifndef MY_HEADER_H
#define MY_HEADER_H

/* 声明 */

#endif
```

守卫宏名要唯一，通常用文件路径大写 + `_H`。`#pragma once` 更简洁，但不是标准；两者不要同时依赖。

**assert**

```c
#include <assert.h>

assert(v != NULL);
assert(v->size <= v->capacity);
```

- `assert` 检查“程序内部不应该发生”的情况，不是用户输入。
- 定义 `NDEBUG` 后 `assert` 被编译掉，表达式不会求值；不要在 `assert` 里写有副作用的代码。
- 发布版本通常加 `-DNDEBUG`；测试版本不要加。

**静态断言**

```c
_Static_assert(sizeof(int) == 4, "int must be 4 bytes");
```

C11 的 `_Static_assert` 在编译期检查，不生成运行时代码。适合检查类型宽度、结构体大小、平台假设。C23 提供 `static_assert` 宏。

**数组长度宏**

```c
#define ARRAY_LEN(a) (sizeof(a) / sizeof((a)[0]))
```

只能用于真正的数组，不能用于指针：

```c
int a[10];
size_t n = ARRAY_LEN(a);   /* 10 */

int *p = a;
size_t m = ARRAY_LEN(p);   /* 错误：得到指针大小 / 元素大小 */
```

**offsetof 和 container_of**

```c
#include <stddef.h>

#define container_of(ptr, type, member) \
    ((type *)((char *)(ptr) - offsetof(type, member)))
```

`offsetof(type, member)` 给出成员在结构体中的字节偏移，`container_of` 由成员地址反推结构体地址。这是 Linux 内核链表的核心技巧，初学了然即可。

**变参宏**

```c
#define LOG(fmt, ...) \
    fprintf(stderr, "[%s:%d] " fmt "\n", __FILE__, __LINE__, __VA_ARGS__)
```

- `...` 和 `__VA_ARGS__` 是 C99 的变参宏。
- 调用时至少要传一个可变参数，否则展开后可能多一个逗号；C23 的 `__VA_OPT__` 可以处理空参数。
- 宏参数里的逗号可能被当成参数分隔符，必要时用括号包起来。

**调试宏**

```c
#ifdef DEBUG
#define DBG(fmt, ...) \
    fprintf(stderr, "[%s:%d] " fmt "\n", __FILE__, __LINE__, __VA_ARGS__)
#else
#define DBG(fmt, ...) ((void)0)
#endif
```

`__FILE__`、`__LINE__` 是预定义宏；`__func__` 是函数内的静态字符串（C99）。

**宏的检查清单**

- 参数和整体是否都加了括号？
- 参数是否被求值多次？
- 宏展开后是否是一个完整语句？
- 宏名是否全大写、是否可能和变量重名？
- 是否可以用 `static inline` 函数代替？
- 是否在头文件里定义了非 `static` 的函数/变量？

## 9. 错误处理

C 没有异常。错误必须通过返回值、输出参数、`errno` 或全局状态传出去。

**统一状态码**

```c
typedef enum {
    DS_OK = 0,
    DS_ERR_INVAL = -1,
    DS_ERR_NOMEM = -2,
    DS_ERR_EMPTY = -3,
    DS_ERR_FULL = -4,
    DS_ERR_IO = -5
} DsStatus;
```

约定：

- `0` 成功，负数失败。
- 不同失败原因用不同负值，调用者才能区分“内存不足”和“参数非法”。
- 不要只返回 `bool`，否则错误原因全丢了。
- 函数注释写清楚：失败时输出参数是否被修改。

**返回码 + 输出参数**

```c
int vector_pop(IntVector *v, int *out) {
    if (!v || !out) return DS_ERR_INVAL;
    if (v->size == 0) return DS_ERR_EMPTY;
    v->size--;
    *out = v->data[v->size];
    return DS_OK;
}
```

调用者：

```c
int value;
int rc = vector_pop(&v, &value);
if (rc != DS_OK) {
    fprintf(stderr, "pop failed: %d\n", rc);
    return rc;
}
```

**errno**

标准库函数失败时通常会设置 `errno`，但 `errno` 只有在函数明确失败时才有效：

```c
#include <errno.h>
#include <string.h>

FILE *fp = fopen(path, "r");
if (!fp) {
    int saved = errno;   /* 先保存，后面的清理可能覆盖 errno */
    fprintf(stderr, "%s: %s\n", path, strerror(saved));
    return -1;
}
```

- `perror(prefix)` 等价于打印 `prefix: strerror(errno)`。
- 成功调用不保证把 `errno` 清零，所以判断失败要看函数返回值，不要看 `errno != 0`。
- 在 `goto cleanup` 前保存 `errno`，否则 `fclose`/`free` 可能改变它。

**goto 清理模板**

C 里 `goto` 最正当的用途是统一清理资源：

```c
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

int read_ints(const char *path, int **out, size_t *out_n) {
    FILE *fp = NULL;
    int *buf = NULL;
    size_t n = 0;
    size_t cap = 0;
    int rc = DS_ERR_IO;

    fp = fopen(path, "r");
    if (!fp) goto done;

    int value;
    int got;
    while ((got = fscanf(fp, "%d", &value)) == 1) {
        if (n == cap) {
            size_t new_cap = cap ? cap * 2 : 16;
            if (new_cap < cap || new_cap > SIZE_MAX / sizeof *buf) {
                rc = DS_ERR_NOMEM;
                goto done;
            }
            int *tmp = realloc(buf, new_cap * sizeof *tmp);
            if (!tmp) {
                rc = DS_ERR_NOMEM;
                goto done;
            }
            buf = tmp;
            cap = new_cap;
        }
        buf[n++] = value;
    }

    /* got == 0 表示遇到非法字符；got == EOF 表示正常读完或读错误 */
    if (got != EOF || ferror(fp)) goto done;

    *out = buf;
    *out_n = n;
    buf = NULL;          /* 所有权交给调用者，避免 done 里释放 */
    rc = DS_OK;

done:
    free(buf);
    if (fp) fclose(fp);
    return rc;
}
```

要点：

- 所有资源指针初始化为 `NULL`，`done` 里统一释放。
- 成功时把输出参数赋值，并把局部指针置 `NULL`，防止被清理代码释放。
- 失败时不要修改输出参数（或者先置空，文档写清楚）。
- `goto` 只往下跳到清理段，不要往回跳。
- `fclose` 的返回值在写文件时也应该检查；上面的示例为了简洁省略了。

**assert 还是运行时检查**

| 场景 | 用什么 |
| --- | --- |
| 内部不变量、绝不应该发生的情况 | `assert` |
| 用户输入、文件内容、网络数据 | 运行时检查 + 返回错误 |
| 分配失败 | 返回 `DS_ERR_NOMEM` |
| 数组下标越界（库内部 bug） | `assert` + 防御性检查 |
| 不可恢复的配置错误 | 打印错误并 `exit`/`abort` |

```c
assert(v != NULL);
assert(v->size <= v->capacity);

if (index >= v->size) {
    return DS_ERR_INVAL;   /* 这是调用者的错误，不是内部不变量 */
}
```

`assert` 在 `-DNDEBUG` 下会被去掉，所以不能把必须执行的逻辑放进 `assert`：

```c
assert(init() == 0);   /* 错误：发布版本不会调用 init */
```

**整数溢出检查**

有符号加法：

```c
#include <limits.h>

int add_overflow(int a, int b, int *out) {
    if ((b > 0 && a > INT_MAX - b) ||
        (b < 0 && a < INT_MIN - b)) {
        return -1;
    }
    *out = a + b;
    return 0;
}
```

无符号加法：

```c
if (a > UINT_MAX - b) {
    /* 溢出 */
}
```

乘法转成除法检查：

```c
if (a != 0 && b > INT_MAX / a) {
    /* a * b 会溢出（假设 a、b 为正） */
}
```

分配大小检查：

```c
if (n > SIZE_MAX / elem_size) {
    return DS_ERR_NOMEM;
}
```

**部分初始化**

申请资源的过程中失败，要把已经申请的资源释放掉：

```c
Vector *vector_create(size_t cap) {
    Vector *v = malloc(sizeof *v);
    if (!v) return NULL;

    v->data = NULL;
    v->size = 0;
    v->capacity = 0;

    if (cap > 0) {
        v->data = malloc(cap * sizeof *v->data);
        if (!v->data) {
            free(v);
            return NULL;
        }
        v->capacity = cap;
    }
    return v;
}
```

顺序很重要：先初始化字段，再申请可能失败的资源；失败路径要能从任意一步安全退出。

**释放后置空**

```c
free(v->data);
v->data = NULL;
v->size = 0;
v->capacity = 0;
```

置空不是防 double free 的万能药（别的指针副本仍可能悬空），但能减少误用。容器的 `destroy` 应该可以重复调用而不崩。

**错误信息**

错误信息要包含上下文，不要只打印 `"failed"`：

```c
fprintf(stderr, "vector_push: out of memory (size=%zu)\n", v->size);
```

库函数不要直接 `printf` 到 stdout，也不要随便 `exit`；把错误返回给调用者，由应用层决定怎么显示、是否退出。

**不要用异常模拟**

- `setjmp/longjmp` 能实现非局部跳转，但会跳过清理逻辑，容易泄漏，数据结构代码里不要用。
- 不要用全局错误字符串代替返回码；多线程下会互相覆盖。
- 不要用 `abort` 处理可恢复错误；`abort` 只用于“程序已经不可能正确继续”。

**错误路径也要测试**

正常路径测试只覆盖一半代码。至少测试：

- 空容器 `pop` / `top`。
- `malloc` 返回 `NULL`（用包装函数注入失败）。
- 容量刚好用完、扩容失败。
- 下标等于 `size`、`size - 1`、`0`。
- 重复 key、删除不存在的 key。
- 文件不存在、读到一半出错。

分配失败注入示例：

```c
#ifdef TEST_FAIL_ALLOC
static int fail_after = 0;
void *test_malloc(size_t n) {
    if (fail_after-- == 0) return NULL;
    return malloc(n);
}
#define malloc test_malloc
#endif
```

这类宏会污染全局，只建议在专门的测试编译单元里用；更干净的做法是把分配器做成函数指针传给容器。

**qsort**

`qsort` 可以排序任意连续数组，元素按字节交换：

```c
#include <stdio.h>
#include <stdlib.h>

static int cmp_int(const void *pa, const void *pb) {
    int a = *(const int *)pa;
    int b = *(const int *)pb;
    return (a > b) - (a < b);
}

int main(void) {
    int a[] = {5, 2, 9, 1, 5, 6};
    size_t n = sizeof a / sizeof a[0];

    qsort(a, n, sizeof a[0], cmp_int);

    for (size_t i = 0; i < n; ++i) {
        printf("%d ", a[i]);
    }
    printf("\n");
    return 0;
}
```

比较器必须满足：

- 返回负数表示 `a < b`，0 表示相等，正数表示 `a > b`。
- 对同一组元素，比较结果要一致（全序）。
- 不要返回 `a - b`，可能溢出。
- 不要修改元素。

**按结构体字段排序**

```c
typedef struct {
    int id;
    int score;
} Student;

static int cmp_student(const void *pa, const void *pb) {
    const Student *a = pa;
    const Student *b = pb;

    /* 分数从高到低 */
    if (a->score != b->score) {
        return (a->score < b->score) ? 1 : -1;
    }
    /* 分数相同按 id 升序 */
    return (a->id > b->id) - (a->id < b->id);
}

qsort(students, n, sizeof students[0], cmp_student);
```

`qsort` 不保证稳定排序。如果“分数相同保持原顺序”很重要，在结构体里加一个原始下标，比较时作为最后的决胜字段。

**排序字符串指针**

```c
#include <string.h>

static int cmp_str(const void *pa, const void *pb) {
    const char *a = *(const char *const *)pa;
    const char *b = *(const char *const *)pb;
    return strcmp(a, b);
}

char *names[] = {"Tom", "Alice", "Bob"};
qsort(names, 3, sizeof names[0], cmp_str);
```

`names` 是“指针的数组”，`qsort` 交换的是指针，不会移动字符串本身。

**bsearch**

`bsearch` 要求数组已经按同一个比较器排好序：

```c
int key = 7;
int *found = bsearch(&key, a, n, sizeof a[0], cmp_int);
if (found) {
    printf("found at index %td\n", found - a);
} else {
    printf("not found\n");
}
```

- 返回指向匹配元素的 `void *`，找不到返回 `NULL`。
- 数组必须有序，比较器必须和 `qsort` 用的一致。
- 有重复元素时返回哪一个不确定。

**qsort 不能直接排序链表**

链表结点不连续，`qsort` 按字节交换会破坏 `next` 指针。链表排序要么：

- 把结点指针收集到数组，对数组 `qsort`，再按顺序重连。
- 自己实现归并排序（链表归并排序很自然，`O(n log n)`，不需要随机访问）。

**rand 和 srand**

```c
#include <stdlib.h>
#include <time.h>

srand((unsigned)time(NULL));
int r = rand() % 100;   /* 0..99，低位随机性较差，测试够用 */
```

- `rand()` 的质量因实现而异，不适合模拟、加密、严格统计。
- `rand() % n` 有轻微偏差；要求均匀时用拒绝采样。
- 测试数据结构时最好用固定种子，保证可复现。
- 不要每次调用都 `srand`，否则序列会重复。

**clock**

```c
#include <time.h>

clock_t start = clock();
/* 运行代码 */
clock_t end = clock();
double seconds = (double)(end - start) / CLOCKS_PER_SEC;
```

`clock()` 测的是 CPU 时间，不是墙钟时间；多线程/IO 等待时和实际耗时不同。要高精度墙钟时间，Linux/macOS 用 `clock_gettime`，C11 可用 `timespec_get`。

**memcpy / memmove / memset / memcmp**

```c
void *memcpy(void *dest, const void *src, size_t n);
void *memmove(void *dest, const void *src, size_t n);
void *memset(void *s, int c, size_t n);
int memcmp(const void *a, const void *b, size_t n);
```

- `memcpy`：不重叠，通常最快。
- `memmove`：允许重叠，内部会判断方向。
- `memset`：按字节填充，只适合清零或填充字节模式。
- `memcmp`：逐字节比较，按 `unsigned char` 解释；不要用来比较含填充的结构体。

**abs 的坑**

```c
int x = INT_MIN;
int y = abs(x);   /* 未定义行为：|INT_MIN| 超出 int 范围 */
```

对 `INT_MIN` 取绝对值要提升到更宽的类型，或单独处理。

**标准库使用原则**

- 用 `size_t` 表示长度，格式用 `%zu`。
- 用 `snprintf` 而不是 `sprintf`。
- 用 `memmove` 处理可能重叠的区间。
- 用 `qsort` 排序数组，链表自己归并。
- 用 `bsearch` 前先排序。
- 用 `strtol` 而不是 `atoi` 做解析。
- 用 `fgets` 而不是 `gets`/无限宽 `%s`。
- 用 `perror`/`strerror` 输出系统错误。
- 用 `assert` 抓内部不变量，不要抓用户输入。

## 11. 数据结构

这一节不重复讲算法证明，重点是把“数据结构”翻译成安全的 C 代码：表示、初始化、扩容、释放、错误处理。

**统一约定**

- 下标从 0 开始。
- 长度、容量、下标统一用 `size_t`。
- 容器维护 `size <= capacity`。
- 成功返回 `0`，失败返回负数；需要输出值时用 `out` 参数。
- 每个容器都有 `init/create` 和 `destroy/free`；`destroy` 允许传 `NULL`，且可重复调用。
- 接口注释写清楚：是否拥有元素、失败时输出参数是否改变、时间复杂度。

**选型速查**

| 结构 | 随机访问 | 查找 | 头部插入/删除 | 尾部插入 | 内存 |
| --- | --- | --- | --- | --- | --- |
| 动态数组 | `O(1)` | `O(n)` | `O(n)` | 均摊 `O(1)` | 连续，缓存友好 |
| 单链表 | `O(n)` | `O(n)` | `O(1)` | 有尾指针时 `O(1)` | 每结点一个指针 |
| 双链表 | `O(n)` | `O(n)` | `O(1)` | 有尾指针时 `O(1)` | 每结点两个指针 |
| 栈 | 只看栈顶 | `O(n)` | `O(1)` | `O(1)` | 数组或链表 |
| 队列 | 只看队头 | `O(n)` | `O(1)` | `O(1)` | 循环数组或链表 |
| 二叉堆 | 只看堆顶 | `O(n)` | — | `O(log n)` | 数组，紧凑 |
| 二叉搜索树 | `O(log n)` 平均 | `O(log n)` 平均 | — | `O(log n)` 平均 | 每结点两个指针 |
| 哈希表 | — | 平均 `O(1)` | — | 平均 `O(1)` | 桶 + 结点 |
| 邻接矩阵 | `O(1)` 查边 | — | — | — | `O(V^2)` |
| 邻接表 | `O(deg)` 查边 | — | — | — | `O(V+E)` |

“平均”和“最坏”要分开看：哈希表最坏 `O(n)`，普通 BST 退化后也是 `O(n)`。

**动态数组**

核心：`data` 指向连续内存，`size` 是已用元素数，`capacity` 是已分配容量。`size == capacity` 时扩容，通常乘 2。

```c
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct {
    int *data;
    size_t size;
    size_t capacity;
} IntVector;

static int vector_reserve(IntVector *v, size_t need) {
    if (need <= v->capacity) return 0;

    size_t cap = v->capacity ? v->capacity : 4;
    while (cap < need) {
        if (cap > SIZE_MAX / 2) {
            cap = need;
            break;
        }
        cap *= 2;
    }

    if (cap > SIZE_MAX / sizeof *v->data) return -1;

    int *tmp = realloc(v->data, cap * sizeof *tmp);
    if (!tmp) return -1;

    v->data = tmp;
    v->capacity = cap;
    return 0;
}

int vector_init(IntVector *v, size_t cap) {
    if (!v) return -1;
    v->data = NULL;
    v->size = 0;
    v->capacity = 0;
    return vector_reserve(v, cap);
}

void vector_destroy(IntVector *v) {
    if (!v) return;
    free(v->data);
    v->data = NULL;
    v->size = 0;
    v->capacity = 0;
}

int vector_push(IntVector *v, int value) {
    if (!v) return -1;
    if (v->size == SIZE_MAX) return -1;
    if (vector_reserve(v, v->size + 1) != 0) return -1;
    v->data[v->size++] = value;
    return 0;
}

int vector_pop(IntVector *v, int *out) {
    if (!v || v->size == 0) return -1;
    v->size--;
    if (out) *out = v->data[v->size];
    return 0;
}

int vector_get(const IntVector *v, size_t index, int *out) {
    if (!v || !out || index >= v->size) return -1;
    *out = v->data[index];
    return 0;
}

size_t vector_size(const IntVector *v) {
    return v ? v->size : 0;
}
```

关键点：

- `vector_reserve` 只在 `need > capacity` 时扩容。
- 扩容用临时指针接收 `realloc`，失败时原内存仍然有效。
- 扩容后旧指针/迭代器全部失效。
- `vector_push` 均摊 `O(1)`：扩容一次搬 `n` 个，但摊到每次插入是常数。
- `vector_pop` 只减 `size`，不释放内存；容量保留，方便复用。
- `vector_destroy` 可重复调用：`free(NULL)` 安全，字段也归零。
- 如果元素本身持有堆内存，`vector_destroy` 只释放数组，不会释放元素内部指针；需要额外的 `destroy_element` 回调。

**链式存储 vs 顺序存储**

- 动态数组：随机访问快、缓存友好、扩容有搬迁成本、中间插入删除要搬元素。
- 链表：插入删除不需要搬元素，但每个结点多一个指针，随机访问要遍历，缓存不友好。
- 大多数“读多写少、以下标访问为主”的场景，动态数组更快，哪怕理论复杂度不是最优。
- 只有频繁在已知位置插入/删除、或元素很大不便搬迁时，链表才有明显优势。

**单链表**

```c
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;
} Node;
```

**头插**

```c
int list_push_front(Node **head, int value) {
    if (!head) return -1;
    Node *node = malloc(sizeof *node);
    if (!node) return -1;
    node->value = value;
    node->next = *head;
    *head = node;
    return 0;
}
```

用 `Node **head` 而不是 `Node *head`，因为要修改调用者的头指针。如果只传 `Node *head`，函数内改的是副本，调用者看不到。

**删除第一个匹配结点**

```c
int list_remove(Node **head, int value) {
    if (!head) return -1;

    Node **link = head;
    while (*link && (*link)->value != value) {
        link = &(*link)->next;
    }
    if (!*link) return -1;

    Node *victim = *link;
    *link = victim->next;
    free(victim);
    return 0;
}
```

`link` 是“指向指针的指针”：它一开始指向 `head`，之后指向某个结点的 `next` 字段。找到目标后，`*link = victim->next` 一行就能处理“删除头结点”和“删除中间结点”两种情况，不需要特判。

**释放整条链表**

```c
void list_free(Node **head) {
    if (!head) return;
    Node *cur = *head;
    while (cur) {
        Node *next = cur->next;   /* 先保存 next，再 free */
        free(cur);
        cur = next;
    }
    *head = NULL;
}
```

如果先 `free(cur)` 再读 `cur->next`，就是释放后使用。

**反转链表**

```c
Node *list_reverse(Node *head) {
    Node *prev = NULL;
    while (head) {
        Node *next = head->next;
        head->next = prev;
        prev = head;
        head = next;
    }
    return prev;
}
```

三个指针：`prev` 已反转部分的头，`head` 当前结点，`next` 暂存后续。时间复杂度 `O(n)`，空间 `O(1)`。

**判环（Floyd）**

```c
int list_has_cycle(const Node *head) {
    const Node *slow = head;
    const Node *fast = head;

    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return 1;
    }
    return 0;
}
```

快指针每次走两步，慢指针走一步；有环一定相遇，无环快指针先到 `NULL`。

**虚拟头结点**

删除操作多时，可以加一个不存数据的哑结点，让“删除头结点”不再特殊：

```c
Node dummy = { .value = 0, .next = head };
Node **link = &dummy.next;

/* 用 link 做删除 ... */

head = dummy.next;
```

哑结点在栈上，不能 `free(&dummy)`；它只是临时占位。

**尾指针**

只在头部操作时，单链表 `O(1)`；要在尾部追加，维护一个 `tail` 指针：

```c
typedef struct {
    Node *head;
    Node *tail;
    size_t size;
} List;

void list_init(List *list) {
    if (!list) return;
    list->head = NULL;
    list->tail = NULL;
    list->size = 0;
}

int list_append(List *list, int value) {
    if (!list) return -1;
    Node *node = malloc(sizeof *node);
    if (!node) return -1;
    node->value = value;
    node->next = NULL;

    if (list->tail) {
        list->tail->next = node;
    } else {
        list->head = node;
    }
    list->tail = node;
    list->size++;
    return 0;
}
```

删除尾结点时，单链表需要从头找到前驱，仍是 `O(n)`；要 `O(1)` 删除尾结点，用双链表。`list_append` 依赖 `List` 已经初始化，使用前先 `list_init` 或 `List list = {0};`。

**双链表**

```c
typedef struct DNode {
    int value;
    struct DNode *prev;
    struct DNode *next;
} DNode;
```

已知结点指针时，删除是 `O(1)`：

```c
void dlist_remove(DNode **head, DNode *node) {
    if (!head || !node) return;

    if (node->prev) {
        node->prev->next = node->next;
    } else {
        *head = node->next;
    }
    if (node->next) {
        node->next->prev = node->prev;
    }
    free(node);
}
```

如果链表还维护 `tail` 指针，删除尾结点后还要把 `tail` 更新为 `node->prev`。

双链表的每个结点多一个指针，插入/删除时要同时维护 `prev` 和 `next`，容易漏改。可以加头尾哨兵结点，把边界情况统一掉。

**栈**

栈是“后进先出”，只需要 `push`、`pop`、`top`、`empty`。用动态数组实现最简单：

```c
typedef IntVector Stack;

int stack_push(Stack *s, int value) {
    return vector_push(s, value);
}

int stack_pop(Stack *s, int *out) {
    return vector_pop(s, out);
}

int stack_top(const Stack *s, int *out) {
    if (!s || s->size == 0) return -1;
    return vector_get(s, s->size - 1, out);
}
```

注意 `s->size - 1` 在 `size == 0` 时会回绕成 `SIZE_MAX`，所以必须先判断空。

用链表实现栈就是“头插 + 头删”，`push/pop` 都是 `O(1)`；数组栈的 `push` 均摊 `O(1)`，缓存更好。

栈的典型用途：

- 括号匹配、表达式求值、后缀表达式。
- DFS 的非递归实现。
- 函数调用、撤销操作、浏览器后退。
- 单调栈（下一个更大元素、柱状图最大矩形）。

**队列**

队列是“先进先出”。用数组时不要每次 `pop` 都整体前移，而是用循环缓冲区。

```c
#include <stddef.h>
#include <stdlib.h>

typedef struct {
    int *data;
    size_t capacity;
    size_t head;
    size_t size;
} IntQueue;

int queue_init(IntQueue *q, size_t cap) {
    if (!q || cap == 0) return -1;
    q->data = malloc(cap * sizeof *q->data);
    if (!q->data) return -1;
    q->capacity = cap;
    q->head = 0;
    q->size = 0;
    return 0;
}

void queue_destroy(IntQueue *q) {
    if (!q) return;
    free(q->data);
    q->data = NULL;
    q->capacity = 0;
    q->head = 0;
    q->size = 0;
}

int queue_push(IntQueue *q, int value) {
    if (!q || q->size == q->capacity) return -1;
    size_t tail = (q->head + q->size) % q->capacity;
    q->data[tail] = value;
    q->size++;
    return 0;
}

int queue_pop(IntQueue *q, int *out) {
    if (!q || q->size == 0) return -1;
    if (out) *out = q->data[q->head];
    q->head = (q->head + 1) % q->capacity;
    q->size--;
    return 0;
}

int queue_empty(const IntQueue *q) {
    return !q || q->size == 0;
}
```

- `head` 指向队头，`tail = (head + size) % capacity`。
- 用 `size` 区分空和满，比“留一个空位”的写法更直观。
- 固定容量满了就返回错误；需要动态扩容时，申请更大的数组，把元素按顺序复制过去，再重置 `head = 0`。
- 扩容是 `O(n)`，但均摊到每次入队仍是 `O(1)`（按倍增策略）。

链表队列：

```c
typedef struct QNode {
    int value;
    struct QNode *next;
} QNode;

typedef struct {
    QNode *head;
    QNode *tail;
    size_t size;
} LinkedQueue;
```

- 入队：在 `tail` 后接新结点，更新 `tail`。
- 出队：删除 `head`，如果删完 `head == NULL`，把 `tail` 也置 `NULL`。
- 每个结点一次 `malloc`，内存开销比循环数组大。

队列的典型用途：

- BFS。
- 任务调度、生产者消费者（多线程时要加锁/条件变量）。
- 滑动窗口、层序遍历。
- 单调队列（滑动窗口最值）。

**二叉堆**

堆是“完全二叉树 + 堆序”，用数组存最省内存。下标 `i` 的父结点是 `(i-1)/2`，左孩子是 `2i+1`，右孩子是 `2i+2`。

下面是最小堆：

```c
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct {
    int *data;
    size_t size;
    size_t capacity;
} MinHeap;

static void swap_int(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

static void heap_sift_up(MinHeap *h, size_t i) {
    while (i > 0) {
        size_t parent = (i - 1) / 2;
        if (h->data[parent] <= h->data[i]) break;
        swap_int(&h->data[parent], &h->data[i]);
        i = parent;
    }
}

static void heap_sift_down(MinHeap *h, size_t i) {
    for (;;) {
        size_t left = i * 2 + 1;
        size_t right = left + 1;
        size_t smallest = i;

        if (left < h->size && h->data[left] < h->data[smallest]) {
            smallest = left;
        }
        if (right < h->size && h->data[right] < h->data[smallest]) {
            smallest = right;
        }
        if (smallest == i) break;

        swap_int(&h->data[i], &h->data[smallest]);
        i = smallest;
    }
}

int heap_init(MinHeap *h, size_t cap) {
    if (!h) return -1;
    h->data = NULL;
    h->size = 0;
    h->capacity = 0;
    if (cap == 0) return 0;
    h->data = malloc(cap * sizeof *h->data);
    if (!h->data) return -1;
    h->capacity = cap;
    return 0;
}

void heap_destroy(MinHeap *h) {
    if (!h) return;
    free(h->data);
    h->data = NULL;
    h->size = 0;
    h->capacity = 0;
}

int heap_push(MinHeap *h, int value) {
    if (!h) return -1;
    if (h->size == h->capacity) {
        size_t new_cap = h->capacity ? h->capacity * 2 : 4;
        if (new_cap < h->capacity || new_cap > SIZE_MAX / sizeof *h->data) {
            return -1;
        }
        int *tmp = realloc(h->data, new_cap * sizeof *tmp);
        if (!tmp) return -1;
        h->data = tmp;
        h->capacity = new_cap;
    }

    size_t i = h->size++;
    h->data[i] = value;
    heap_sift_up(h, i);
    return 0;
}

int heap_pop(MinHeap *h, int *out) {
    if (!h || h->size == 0) return -1;
    if (out) *out = h->data[0];

    h->size--;
    if (h->size > 0) {
        h->data[0] = h->data[h->size];
        heap_sift_down(h, 0);
    }
    return 0;
}

int heap_top(const MinHeap *h, int *out) {
    if (!h || !out || h->size == 0) return -1;
    *out = h->data[0];
    return 0;
}

void heap_build(MinHeap *h) {
    if (!h || h->size < 2) return;
    for (size_t i = h->size / 2; i > 0; ) {
        --i;
        heap_sift_down(h, i);
    }
}
```

- `push`：放到数组末尾，向上调整，`O(log n)`。
- `pop`：取走堆顶，把最后一个元素放到堆顶，向下调整，`O(log n)`。
- `build`：从最后一个非叶结点往前 `sift_down`，总复杂度 `O(n)`，不是 `O(n log n)`。
- 最大堆只需把比较方向反过来，或者存 `-value`。
- 堆只能快速拿到最值，不能快速查找任意元素；删除任意元素需要额外维护位置索引。

堆的用途：优先队列、Dijkstra、Huffman、Top-K、任务调度。

**二叉搜索树**

性质：左子树所有 key 小于根，右子树所有 key 大于根。中序遍历得到升序序列。

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int key;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

static TreeNode *tree_new(int key) {
    TreeNode *node = malloc(sizeof *node);
    if (!node) return NULL;
    node->key = key;
    node->left = NULL;
    node->right = NULL;
    return node;
}

/* 返回 1 表示插入，0 表示已存在，-1 表示分配失败 */
int bst_insert(TreeNode **root, int key) {
    if (!root) return -1;

    while (*root) {
        if (key == (*root)->key) return 0;
        if (key < (*root)->key) {
            root = &(*root)->left;
        } else {
            root = &(*root)->right;
        }
    }

    *root = tree_new(key);
    return *root ? 1 : -1;
}

TreeNode *bst_find(TreeNode *root, int key) {
    while (root) {
        if (key == root->key) return root;
        root = key < root->key ? root->left : root->right;
    }
    return NULL;
}

void tree_inorder(const TreeNode *root) {
    if (!root) return;
    tree_inorder(root->left);
    printf("%d ", root->key);
    tree_inorder(root->right);
}

void tree_preorder(const TreeNode *root) {
    if (!root) return;
    printf("%d ", root->key);
    tree_preorder(root->left);
    tree_preorder(root->right);
}

void tree_postorder(const TreeNode *root) {
    if (!root) return;
    tree_postorder(root->left);
    tree_postorder(root->right);
    printf("%d ", root->key);
}

void tree_free(TreeNode *root) {
    if (!root) return;
    tree_free(root->left);
    tree_free(root->right);
    free(root);
}
```

`bst_insert` 用 `TreeNode **` 沿树走，找到空位置后直接挂上去；分配失败时原树不被破坏。

**删除结点**

分三种情况：

1. 叶子：直接删。
2. 只有一个孩子：用孩子替代。
3. 两个孩子：用右子树最小结点（后继）的 key 替换，再删后继。

```c
TreeNode *bst_delete(TreeNode *root, int key) {
    if (!root) return NULL;

    if (key < root->key) {
        root->left = bst_delete(root->left, key);
    } else if (key > root->key) {
        root->right = bst_delete(root->right, key);
    } else {
        if (!root->left) {
            TreeNode *right = root->right;
            free(root);
            return right;
        }
        if (!root->right) {
            TreeNode *left = root->left;
            free(root);
            return left;
        }

        TreeNode *succ = root->right;
        while (succ->left) succ = succ->left;
        root->key = succ->key;
        root->right = bst_delete(root->right, succ->key);
    }
    return root;
}
```

删除用递归实现最简洁，但树退化时递归深度是 `O(n)`；极大/恶意数据要改成迭代或平衡树。

**BST 的复杂度**

- 平均（随机插入）：查找/插入/删除 `O(log n)`。
- 最坏（有序插入）：退化成链表，`O(n)`。
- 要保证最坏 `O(log n)`，用 AVL、红黑树、B 树等平衡结构；C 标准库没有现成的。
- 堆不是 BST：堆只保证父子大小关系，不保证中序有序，不能用来查找任意 key。

**树的遍历**

- 前序：根 → 左 → 右，适合复制树、前缀表达式。
- 中序：左 → 根 → 右，BST 得到升序。
- 后序：左 → 右 → 根，适合释放树、后缀表达式。
- 层序：按层访问，用队列实现 BFS。

递归遍历代码短，但深度等于树高。退化树（例如按 1,2,3,... 插入）高度 `O(n)`，递归可能栈溢出。工程上要么用平衡树，要么用显式栈：

```c
/* 中序非递归：左链一路压栈，弹出访问，再转向右子树 */
void tree_inorder_iter(TreeNode *root) {
    TreeNode **stack = NULL;
    size_t top = 0;
    size_t cap = 0;

    while (root || top > 0) {
        while (root) {
            if (top == cap) {
                size_t new_cap = cap ? cap * 2 : 16;
                TreeNode **tmp = realloc(stack, new_cap * sizeof *tmp);
                if (!tmp) {
                    free(stack);
                    return;   /* 分配失败，示例里直接放弃遍历 */
                }
                stack = tmp;
                cap = new_cap;
            }
            stack[top++] = root;
            root = root->left;
        }
        root = stack[--top];
        printf("%d ", root->key);
        root = root->right;
    }
    free(stack);
}
```

**完全二叉树的数组表示**

如果树是完全二叉树，可以用数组存，不存指针：

```text
结点 i 的左孩子：2*i + 1
结点 i 的右孩子：2*i + 2
结点 i 的父结点：(i - 1) / 2
```

堆就是这样存的。普通二叉树用数组会浪费大量空间，且插入/删除要搬元素，不合适。

**哈希表**

哈希表用“哈希函数 + 冲突处理”把 key 映射到桶。这里用拉链法：每个桶挂一条链表。

```c
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

typedef struct HashNode {
    char *key;
    int value;
    struct HashNode *next;
} HashNode;

typedef struct {
    HashNode **buckets;
    size_t bucket_count;
    size_t size;
} HashMap;

static uint64_t hash_str(const char *s) {
    /* FNV-1a 64 位 */
    uint64_t h = 14695981039346656037ull;
    while (*s) {
        h ^= (unsigned char)*s++;
        h *= 1099511628211ull;
    }
    return h;
}

static char *dup_key(const char *s) {
    size_t n = strlen(s) + 1;
    char *p = malloc(n);
    if (p) memcpy(p, s, n);
    return p;
}

int hashmap_init(HashMap *m, size_t bucket_count) {
    if (!m || bucket_count == 0) return -1;
    m->buckets = NULL;
    m->bucket_count = 0;
    m->size = 0;
    m->buckets = calloc(bucket_count, sizeof *m->buckets);
    if (!m->buckets) return -1;
    m->bucket_count = bucket_count;
    return 0;
}

void hashmap_destroy(HashMap *m) {
    if (!m || !m->buckets) return;
    for (size_t i = 0; i < m->bucket_count; ++i) {
        HashNode *node = m->buckets[i];
        while (node) {
            HashNode *next = node->next;
            free(node->key);
            free(node);
            node = next;
        }
    }
    free(m->buckets);
    m->buckets = NULL;
    m->bucket_count = 0;
    m->size = 0;
}

static int hashmap_resize(HashMap *m, size_t new_count) {
    HashNode **new_buckets = calloc(new_count, sizeof *new_buckets);
    if (!new_buckets) return -1;

    for (size_t i = 0; i < m->bucket_count; ++i) {
        HashNode *node = m->buckets[i];
        while (node) {
            HashNode *next = node->next;
            size_t idx = (size_t)(hash_str(node->key) % new_count);
            node->next = new_buckets[idx];
            new_buckets[idx] = node;
            node = next;
        }
    }

    free(m->buckets);
    m->buckets = new_buckets;
    m->bucket_count = new_count;
    return 0;
}

int hashmap_put(HashMap *m, const char *key, int value) {
    if (!m || !key || !m->buckets || m->bucket_count == 0) return -1;

    size_t idx = (size_t)(hash_str(key) % m->bucket_count);
    for (HashNode *node = m->buckets[idx]; node; node = node->next) {
        if (strcmp(node->key, key) == 0) {
            node->value = value;
            return 0;
        }
    }

    /* 负载因子超过 3/4 就扩容 */
    if (m->size + 1 > m->bucket_count - m->bucket_count / 4) {
        size_t new_count = m->bucket_count * 2;
        if (new_count < m->bucket_count || hashmap_resize(m, new_count) != 0) {
            return -1;
        }
        idx = (size_t)(hash_str(key) % m->bucket_count);
    }

    HashNode *node = malloc(sizeof *node);
    if (!node) return -1;
    node->key = dup_key(key);
    if (!node->key) {
        free(node);
        return -1;
    }
    node->value = value;
    node->next = m->buckets[idx];
    m->buckets[idx] = node;
    m->size++;
    return 0;
}

int hashmap_get(const HashMap *m, const char *key, int *out) {
    if (!m || !key || !out || !m->buckets || m->bucket_count == 0) return -1;

    size_t idx = (size_t)(hash_str(key) % m->bucket_count);
    for (const HashNode *node = m->buckets[idx]; node; node = node->next) {
        if (strcmp(node->key, key) == 0) {
            *out = node->value;
            return 0;
        }
    }
    return -1;
}

int hashmap_remove(HashMap *m, const char *key) {
    if (!m || !key || !m->buckets || m->bucket_count == 0) return -1;

    size_t idx = (size_t)(hash_str(key) % m->bucket_count);
    HashNode **link = &m->buckets[idx];
    while (*link) {
        if (strcmp((*link)->key, key) == 0) {
            HashNode *victim = *link;
            *link = victim->next;
            free(victim->key);
            free(victim);
            m->size--;
            return 0;
        }
        link = &(*link)->next;
    }
    return -1;
}
```

要点：

- `HashNode` 自己保存一份 key 的副本，调用者可以释放原字符串。
- `destroy` 先释放 key，再释放结点，顺序不能反。
- 扩容时重新计算每个 key 的桶下标，不能直接搬桶。
- 负载因子是 `size / bucket_count`，太高冲突多，太低浪费内存；0.75 是常见折中。
- 哈希函数要稳定：同一个 key 每次必须得到同一个值。
- 字符串哈希要遍历整个字符串，长 key 的哈希成本是 `O(len)`。
- 哈希表最坏 `O(n)`（所有 key 冲突），平均 `O(1)`。
- 攻击者可以构造大量冲突 key 做哈希 DoS；安全场景用带随机种子的哈希。

**冲突处理**

- 拉链法：每个桶挂链表。实现简单，删除方便，结点分散。
- 开放寻址：冲突就按规则找下一个空位（线性探测、二次探测、双哈希）。缓存友好，但删除需要墓碑标记，负载因子不能太高。
- 再哈希：冲突时换一个哈希函数。

**哈希表的 key**

- 字符串：按字节哈希，用 `strcmp` 比较。
- 整数：直接混洗位，例如 `x * 2654435761u`，不要直接用 `x % n`（低位分布差）。
- 结构体：逐字段哈希；不要直接哈希 `sizeof(struct)`，填充字节不确定。
- 浮点数：避免直接按位哈希；先规范化 `-0.0`、`NaN`，或改用整数表示。
- 可变对象不能做 key：key 改了，哈希值变了，就找不到了。

**图**

两种基本表示：

**邻接矩阵**：`matrix[i][j]` 表示边，适合稠密图、频繁判断两点是否相邻。

```c
int **matrix_create(int n) {
    int **m = malloc((size_t)n * sizeof *m);
    if (!m) return NULL;
    for (int i = 0; i < n; ++i) {
        m[i] = calloc((size_t)n, sizeof *m[i]);
        if (!m[i]) {
            for (int j = 0; j < i; ++j) free(m[j]);
            free(m);
            return NULL;
        }
    }
    return m;
}
```

- 空间 `O(V^2)`，稀疏图浪费。
- 判断边 `O(1)`，遍历邻居 `O(V)`。
- 带权图把 `0/1` 换成权值，用一个 `INF` 表示没有边。

**邻接表**：每个顶点挂一条边链表，适合稀疏图。

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Edge {
    int to;
    int weight;
    struct Edge *next;
} Edge;

typedef struct {
    Edge **adj;
    int n;
} Graph;

Graph *graph_create(int n) {
    if (n <= 0) return NULL;
    Graph *g = malloc(sizeof *g);
    if (!g) return NULL;
    g->adj = calloc((size_t)n, sizeof *g->adj);
    if (!g->adj) {
        free(g);
        return NULL;
    }
    g->n = n;
    return g;
}

void graph_destroy(Graph *g) {
    if (!g) return;
    for (int i = 0; i < g->n; ++i) {
        Edge *e = g->adj[i];
        while (e) {
            Edge *next = e->next;
            free(e);
            e = next;
        }
    }
    free(g->adj);
    free(g);
}

int graph_add_edge(Graph *g, int from, int to, int weight) {
    if (!g || from < 0 || from >= g->n || to < 0 || to >= g->n) {
        return -1;
    }
    Edge *e = malloc(sizeof *e);
    if (!e) return -1;
    e->to = to;
    e->weight = weight;
    e->next = g->adj[from];
    g->adj[from] = e;
    return 0;
}
```

- 有向图：`add_edge(g, u, v, w)` 一次。
- 无向图：再调用一次 `add_edge(g, v, u, w)`。
- 邻接表遍历邻居 `O(deg(v))`，判断两点是否相邻最坏 `O(deg(v))`。
- 边链表头插，边的顺序和输入相反；需要稳定顺序就尾插或收集到数组。

**BFS**

```c
int graph_bfs(const Graph *g, int start) {
    if (!g || start < 0 || start >= g->n) return -1;

    int *visited = calloc((size_t)g->n, sizeof *visited);
    int *queue = malloc((size_t)g->n * sizeof *queue);
    if (!visited || !queue) {
        free(visited);
        free(queue);
        return -1;
    }

    size_t head = 0;
    size_t tail = 0;
    visited[start] = 1;
    queue[tail++] = start;

    while (head < tail) {
        int v = queue[head++];
        printf("%d ", v);

        for (const Edge *e = g->adj[v]; e; e = e->next) {
            if (!visited[e->to]) {
                visited[e->to] = 1;
                queue[tail++] = e->to;
            }
        }
    }

    free(queue);
    free(visited);
    return 0;
}
```

- 每个顶点最多入队一次，`tail <= n`，所以队列开 `n` 就够。
- BFS 求无权图最短路径（边数最少）；带权图要用 Dijkstra。
- `visited` 在入队时置位，不是在出队时，避免同一个顶点重复入队。

**DFS**

```c
static void dfs_visit(const Graph *g, int v, int *visited) {
    visited[v] = 1;
    printf("%d ", v);
    for (const Edge *e = g->adj[v]; e; e = e->next) {
        if (!visited[e->to]) {
            dfs_visit(g, e->to, visited);
        }
    }
}

int graph_dfs(const Graph *g, int start) {
    if (!g || start < 0 || start >= g->n) return -1;
    int *visited = calloc((size_t)g->n, sizeof *visited);
    if (!visited) return -1;
    dfs_visit(g, start, visited);
    free(visited);
    return 0;
}
```

- DFS 递归深度可能等于 `V`，大图要改成显式栈。
- 遍历所有连通分量：外层再套一个 `for`，对未访问顶点调用 `dfs_visit`。
- 无向图判环：DFS 时记录父结点，遇到已访问且不是父结点的邻居就是环。
- 有向图判环：用三色标记（白/灰/黑），遇到灰色结点说明有后向边。

**拓扑排序（Kahn）**

```c
int graph_toposort(const Graph *g, int *order) {
    if (!g || !order) return -1;

    int *indeg = calloc((size_t)g->n, sizeof *indeg);
    int *queue = malloc((size_t)g->n * sizeof *queue);
    if (!indeg || !queue) {
        free(indeg);
        free(queue);
        return -1;
    }

    for (int v = 0; v < g->n; ++v) {
        for (const Edge *e = g->adj[v]; e; e = e->next) {
            indeg[e->to]++;
        }
    }

    size_t head = 0;
    size_t tail = 0;
    for (int v = 0; v < g->n; ++v) {
        if (indeg[v] == 0) queue[tail++] = v;
    }

    size_t count = 0;
    while (head < tail) {
        int v = queue[head++];
        order[count++] = v;
        for (const Edge *e = g->adj[v]; e; e = e->next) {
            if (--indeg[e->to] == 0) {
                queue[tail++] = e->to;
            }
        }
    }

    free(queue);
    free(indeg);
    return count == (size_t)g->n ? 0 : -1;  /* -1 表示有环 */
}
```

拓扑排序只适用于有向无环图（DAG）。`order` 由调用者提供，长度至少 `g->n`。

**并查集**

并查集维护不相交集合，支持“合并”和“查代表元”，近乎 `O(1)`。

```c
typedef struct {
    int *parent;
    int *size;
    int n;
} DSU;

int dsu_init(DSU *d, int n) {
    if (!d || n <= 0) return -1;
    d->parent = malloc((size_t)n * sizeof *d->parent);
    d->size = malloc((size_t)n * sizeof *d->size);
    if (!d->parent || !d->size) {
        free(d->parent);
        free(d->size);
        return -1;
    }
    for (int i = 0; i < n; ++i) {
        d->parent[i] = i;
        d->size[i] = 1;
    }
    d->n = n;
    return 0;
}

void dsu_destroy(DSU *d) {
    if (!d) return;
    free(d->parent);
    free(d->size);
    d->parent = NULL;
    d->size = NULL;
    d->n = 0;
}

int dsu_find(DSU *d, int x) {
    while (d->parent[x] != x) {
        d->parent[x] = d->parent[d->parent[x]];  /* 路径减半 */
        x = d->parent[x];
    }
    return x;
}

int dsu_union(DSU *d, int a, int b) {
    a = dsu_find(d, a);
    b = dsu_find(d, b);
    if (a == b) return 0;

    if (d->size[a] < d->size[b]) {
        int t = a;
        a = b;
        b = t;
    }
    d->parent[b] = a;
    d->size[a] += d->size[b];
    return 1;
}
```

- 路径压缩：查找时把沿途结点直接挂到根，后续更快。
- 按大小合并：小集合挂到大集合下，树高保持 `O(log n)`。
- 两者结合，均摊复杂度接近 `O(1)`（反阿克曼函数）。
- Kruskal 最小生成树：边按权排序，依次尝试合并，能合并就加入，直到选够 `n-1` 条。

**最短路径**

- 无权图：BFS，第一次访问就是最短边数。
- 非负权图：Dijkstra + 优先队列。核心是“每次取出当前距离最小的未确定顶点”，然后松弛邻居。
- 有负权边：Bellman-Ford / SPFA；Dijkstra 不适用。
- 多源最短路：Floyd-Warshall，`O(V^3)`，适合小图。
- 所有点对最短路也可以用 Johnson（稀疏图 + 重赋权 + Dijkstra）。

Dijkstra 用堆时，同一个顶点可能多次入堆；弹出时如果距离不是最新的就跳过（懒删除）：

```text
while (heap_pop(&pq, &cur)) {
    if (cur.dist != dist[cur.v]) continue;
    for each edge (v -> to, w) {
        if (cur.dist + w < dist[to]) {
            dist[to] = cur.dist + w;
            heap_push(&pq, {dist[to], to});
        }
    }
}
```

C 里需要自己定义“距离 + 顶点”的结构体和堆比较函数，或者把两个 `int` 打包成一个 `int64_t`。

**图的选型**

| 场景 | 推荐 |
| --- | --- |
| 稠密图、频繁查边 | 邻接矩阵 |
| 稀疏图、遍历邻居 | 邻接表 |
| 只关心边、Kruskal | 边列表 |
| 顶点数小、多源最短路 | 邻接矩阵 + Floyd |
| 非负权单源最短路 | 邻接表 + 二叉堆 |
| 动态加边、连通性 | 并查集（只适合无向） |

**复杂度速查**

| 操作 | 动态数组 | 单链表 | 哈希表 | 平衡 BST | 二叉堆 |
| --- | --- | --- | --- | --- | --- |
| 按下标访问 | `O(1)` | `O(n)` | — | — | — |
| 查找 | `O(n)` | `O(n)` | 平均 `O(1)` | `O(log n)` | `O(n)` |
| 头部插入 | `O(n)` | `O(1)` | — | — | — |
| 尾部插入 | 均摊 `O(1)` | 有尾指针 `O(1)` | 平均 `O(1)` | `O(log n)` | `O(log n)` |
| 删除已知结点 | `O(n)` | 需前驱，`O(n)` | 平均 `O(1)` | `O(log n)` | `O(log n)` |
| 取最值 | `O(n)` | `O(n)` | — | `O(log n)` | `O(1)` |

**实现和测试流程**

1. 先写结构体定义和不变量，不急着写操作。
2. 写 `init/create` 和 `destroy/free`，确保空容器可用。
3. 写核心操作，所有失败路径都要能安全返回。
4. 写测试：空、单元素、满、扩容、重复、删除不存在、首尾边界。
5. 打开 `-fsanitize=address,undefined` 跑测试。
6. 用随机操作和朴素实现对比（例如动态数组 vs 直接数组、哈希表 vs 线性查找）。
7. 测性能时用 `-O2`，数据量要足够大，避免被启动开销干扰。
8. 检查泄漏：每个 `malloc` 都要有对应的 `free` 路径。

**边界测试清单**

- 空容器：`pop`、`top`、`get(0)`、`remove` 是否安全返回错误。
- 单元素：删除后容器是否回到空状态，`head/tail` 是否正确。
- 容量为 0 初始化，第一次 `push` 是否正常扩容。
- 扩容失败：原数据是否还在，容器是否仍可用。
- 下标 `0`、`size-1`、`size`、`SIZE_MAX`。
- 重复 key：是覆盖、拒绝还是允许重复？
- 删除头结点、尾结点、唯一结点。
- 环形队列绕回：`head` 接近 `capacity` 时入队/出队。
- 树：空树、单结点、只有左孩子、只有右孩子、退化链。
- 图：孤立点、自环、重边、非连通图、有环图。
- 字符串：空串、超长串、没有 `'\0'` 的缓冲区（不要构造，但要有防护）。

**随机测试示例**

```c
#include <assert.h>
#include <stdlib.h>

static int cmp_int(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);
}

void test_vector_against_array(void) {
    IntVector v;
    assert(vector_init(&v, 0) == 0);

    int ref[1000];
    size_t n = 0;

    for (int step = 0; step < 10000; ++step) {
        if ((rand() % 2 == 0) && n < 1000) {
            int x = rand() % 1000;
            assert(vector_push(&v, x) == 0);
            ref[n++] = x;
        } else if (n > 0) {
            int got;
            assert(vector_pop(&v, &got) == 0);
            assert(got == ref[--n]);
        }
        assert(vector_size(&v) == n);
    }

    vector_destroy(&v);
}
```

这种“随机操作 + 参考实现”能抓到很多手写测试漏掉的边界。

## 12. 调试

C 的 bug 有很大一部分是内存问题。先让工具替你检查，再靠 `printf` 和 gdb 定位逻辑。

**编译选项**

```bash
# 日常开发
gcc -std=c17 -Wall -Wextra -Wpedantic -Wshadow -g -O0 app.c -o app

# 更严格（会有不少噪音，按需开）
gcc -std=c17 -Wall -Wextra -Wconversion -Wsign-conversion -Werror -g -O0 app.c -o app

# 地址 + 未定义行为检查
gcc -std=c17 -g -O1 \
    -fsanitize=address,undefined \
    -fno-omit-frame-pointer \
    app.c -o app
```

- `-Wall -Wextra` 不是“所有警告”，但能覆盖大部分常见问题。
- `-Werror` 会把警告变成错误；新项目可以开，老代码/跨平台代码慎用。
- `-O0` 调试友好；`-O2` 下变量可能被优化掉，断点可能跳行。
- 未定义行为在 `-O0` 和 `-O2` 下表现可能不同；“本地能跑”不代表正确。
- `-fsanitize=address` 在 GCC/Clang 的 Linux、macOS、WSL 上通常可用；MinGW 原生支持不完整，Windows 建议用 WSL 或 Visual Studio 的 ASan。
- `-fsanitize=undefined` 检查有符号溢出、越界移位等未定义行为；空指针解引用有时会直接崩溃，不一定有报告。加 `-fno-sanitize-recover=all` 让错误直接终止。

**AddressSanitizer 能抓什么**

- 堆/栈/全局数组越界。
- 释放后使用（use-after-free）。
- 重复释放（double-free）。
- 内存泄漏（LeakSanitizer，Linux 上通常默认开启；其他平台看工具链支持）。
- 部分未初始化读（MemorySanitizer 更专门，需要 Clang）。

示例：

```bash
gcc -std=c17 -g -O1 -fsanitize=address,undefined -fno-omit-frame-pointer bug.c -o bug
./bug
```

报告里重点看：

- 错误类型：`heap-buffer-overflow`、`use-after-free`、`double-free`、`stack-buffer-overflow`。
- 访问地址和对象范围：`0 bytes after ...`。
- 分配/释放的调用栈：哪一行 `malloc`、哪一行 `free`。
- 最近一次写/读的位置。

**gdb 常用命令**

```bash

gdb ./app
```

**静态分析**


静态分析不能替代运行测试，但能在不运行程序的情况下发现空指针、资源泄漏、越界等模式。

**未定义行为清单**

下面这些行为在 C 标准里都是“未定义”，编译器可以做任何事，包括看起来正常运行：

- 有符号整数溢出：`INT_MAX + 1`。
- 数组越界读写：`a[n]`、`p[-1]`。
- 解引用空指针/悬空指针。
- 释放后继续使用，或重复 `free`。
- 读取未初始化的自动变量。
- 指针加减超出同一数组对象（尾后一位可以形成，但不能解引用）。
- 通过不兼容类型的指针访问对象（strict aliasing）。
- 未对齐的指针访问（例如把 `char *` 强转成 `int *` 后解引用）。
- 修改字符串字面量。
- 移位位数为负或大于等于类型宽度；左移负数。
- 除以零，或 `INT_MIN / -1`。
- 函数声明和定义的类型不一致，却互相调用。
- `printf` 格式符和参数类型不匹配。
- 多个线程无同步地读写同一对象（data race）。

**常见内存错误和症状**

| 错误 | 症状 | 修法 |
| --- | --- | --- |
| 少分配一个字节 | 字符串末尾越界，偶发崩溃 | `strlen + 1`，用 `snprintf` |
| `sizeof(pointer)` 当数组大小 | 只复制 8 字节 | 传数组长度，或 `sizeof array` |
| `free` 后继续用 | 读到垃圾/崩溃 | 释放后置 `NULL`，理清所有权 |
| 返回局部变量地址 | 调用后数据随机 | 用 `malloc` 或调用者缓冲区 |
| `realloc` 直接覆盖原指针 | 失败时泄漏 | 用临时指针 |
| 忘记初始化 | 随机值、条件偶发 | `calloc` 或显式初始化 |
| 越界写 | 破坏堆/栈元数据 | 检查下标，开 ASan |
| 结构体浅拷贝后 double free | 崩溃 | 深拷贝或明确所有权 |
| 队列/栈空时取元素 | 越界/垃圾 | 先判空 |
| 链表断链 | 丢失结点/死循环 | 画图，先保存 `next` |

**调试流程**

1. 复现：固定输入、固定随机种子、固定编译选项。
2. 缩小：删掉无关代码，保留最小失败用例。
3. 工具：先开 ASan/UBSan，再 gdb。
4. 定位：看崩溃栈、变量值、内存布局。
5. 修复：改根因，不是改症状。
6. 回归：加一个能复现该 bug 的测试，防止再犯。

**printf 调试**

```c
fprintf(stderr, "push: size=%zu cap=%zu value=%d\n",
        v->size, v->capacity, value);
```

- 调试输出用 `stderr`，不污染 stdout 的数据。
- 在关键路径打印前后状态，尤其是 `size/capacity/head/tail`。
- 不要在海量循环里打印；用条件或计数器限制。
- 记得在提交前删掉/用 `#ifdef DEBUG` 包起来。

**断言**

```c
assert(v->size <= v->capacity);
assert(index < v->size);
```

断言适合抓“绝不应该发生”的内部错误。测试时不要定义 `NDEBUG`，让断言生效；发布时再关掉。

**性能分析**

- 先测整体时间，再找热点；不要凭感觉优化。
- `-O2` 下测，`-O0` 的数字没有参考价值。
- Linux 可用 `perf record` / `perf report`，或 `valgrind --tool=callgrind`。
- 数据结构层面先看复杂度和内存访问模式，再看常数。
- 链表 vs 数组：理论复杂度相同，实际数组往往更快，因为缓存局部性好。
- 微基准测试要防止编译器把循环优化掉（把结果累加并打印/校验）。

**多线程（了解）**

- C11 有 `<threads.h>` 和 `<stdatomic.h>`，但很多平台/编译器支持不完整。
- 实际项目常用 POSIX 线程（pthread）或平台线程库。
- 数据结构本身通常不加锁；由调用者负责同步。
- 无锁数据结构很难写对，初学不要碰。
- 数据竞争是未定义行为，`-fsanitize=thread` 可以检测部分问题。

## 13. 速查

**声明读法**

从变量名开始，先看右边的 `[]`、`()`，再看左边的 `*`，由内向外读：

```c
int *p;              /* p 是指针，指向 int */
int *const p;        /* p 是常量指针，指向 int */
const int *p;        /* p 是指针，指向 const int */
const int *const p;  /* p 是常量指针，指向 const int */
int (*fp)(int);      /* fp 是函数指针，函数接收 int，返回 int */
int *a[10];          /* a 是数组，含 10 个 int* */
int (*a)[10];        /* a 是指针，指向含 10 个 int 的数组 */
int **pp;            /* pp 是指针，指向 int* */
```

**分配与释放模板**

```c
#include <stdint.h>
#include <stdlib.h>

int *make_array(size_t n) {
    if (n > SIZE_MAX / sizeof(int)) return NULL;
    int *p = malloc(n * sizeof *p);
    if (!p) return NULL;
    for (size_t i = 0; i < n; ++i) {
        p[i] = 0;
    }
    return p;
}

void free_array(int *p) {
    free(p);   /* free(NULL) 安全 */
}
```

- [ ] `size <= capacity`，`capacity > 0` 时 `data != NULL`。

- [ ] 公开 API 的参数/返回值/错误码有注释。
- [ ] 测试覆盖空、单元素、满、扩容、重复、边界。

- [ ] 编译器 `-Wall -Wextra` 没有警告。

**从 Java/Python 过来最容易犯的错**

1. 忘记 `free`，或者释放后继续用。
2. 以为数组会带长度，函数里用 `sizeof` 算长度。
3. 以为 `char *` 是字符串对象，忘了 `'\0'`。
4. 用 `==` 比较字符串内容。
5. 以为有异常，错误不检查返回值。
6. 以为 `int` 溢出会报错/回绕；有符号溢出是未定义行为。
7. 把结构体赋值当成深拷贝。
8. 返回局部变量地址。
9. 用 `scanf("%s")` 读输入。
10. 用 `gets`、`strcpy`、`sprintf` 这些不安全的函数。
11. 混淆数组指针和指针数组。
12. 以为 `const` 变量可以做数组长度。
13. 以为 `void *` 可以做指针算术。
14. 忘记 `#include`，靠“隐式声明”编译。
15. 在头文件里定义函数/变量，导致重复定义。

**术语**

| 术语 | 含义 |
| --- | --- |
| 声明 declaration | 告诉编译器名字和类型，不分配存储 |
| 定义 definition | 分配存储或给出函数体 |
| 链接 linkage | 名字能否跨编译单元可见；`static` 是内部链接 |
| 存储期 storage duration | 自动、静态、动态、线程 |
| 左值 lvalue | 能出现在赋值左边、有确定存储位置的对象 |
| 未定义行为 UB | 标准不规定结果，编译器可以做任何事 |
| 实现定义 | 标准允许实现自己选择，但必须写文档 |
| 序列点 | 表达式求值顺序的约束点；`i = i++` 是未定义行为 |
| 对象 object | 一块存储区域，有类型和值 |
| 对齐 alignment | 对象地址必须是某个值的倍数 |
| 填充 padding | 结构体成员之间/末尾为了对齐插入的字节 |
| 退化 decay | 数组名在表达式中转成首元素指针 |
| 悬空指针 dangling | 指向已释放/已失效对象的指针 |
| 内存泄漏 leak | 分配了但再也无法释放 |

**实现数据结构的固定顺序**

1. 画图：元素怎么放，指针怎么连，空/满/边界长什么样。
2. 定结构体和不变量。
3. 写 `init/create`、`destroy/free`。
4. 写“读”操作（`size`、`get`、`find`）。
5. 写“写”操作（`push`、`insert`、`remove`）。
6. 写扩容/缩容。
7. 写测试，先边界后随机。
8. 开 sanitizer 跑一遍。
9. 补注释：所有权、复杂度、失败语义。
10. 性能测试，确认没有意外的 `O(n)`。

**建议练习**

按顺序实现，每个都配测试：

1. 动态数组：`init/destroy/push/pop/get/reserve`。
2. 单链表：头插、尾插、删除、反转、判环、释放。
3. 栈：括号匹配、后缀表达式求值。
4. 循环队列：BFS 用它。
5. 二叉堆：优先队列、Top-K。
6. BST：插入、查找、删除、三种遍历。
7. 哈希表：字符串 key、扩容、删除。
8. 邻接表图：BFS、DFS、拓扑排序。
9. 并查集：Kruskal。
10. 选做：AVL 树、红黑树、跳表、LRU 缓存。
