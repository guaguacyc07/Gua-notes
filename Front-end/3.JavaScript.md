# JavaScript

## 1. JavaScript 简介

> JavaScript 简称 JS.

JavaScript 是一种轻量级、解释型、面向对象的脚本语言。它主要被设计用于在网页上实现动态效果，增加用户与网页的交互性。

作为一种客户端脚本语言，JavaScript 可以直接嵌入 HTML，并在浏览器中执行。

与 HTML 和 CSS 不同，JavaScript 使得网页不再是静态的，而是可以根据用户的操作动态变化的。

---

## 2. JavaScript 的作用

JavaScript 在前端开发中扮演着重要的角色，其应用领域包括但不限于：

- `客户端脚本`：用于在用户浏览器中执行，实现动态效果和用户交互。
- `网页开发`：与 HTML 和 CSS 协同工作，使得网页具有更强的交互性和动态性。
- `后端开发`：使用 Node.js，JavaScript 也可以在服务器端运行，实现服务器端应用的开发。

## 4. JS 基础语法

### 4.1 变量和数据类型


#### 4.1.1 var 和 let 的区别

两者都用于声明变量，核心区别有 4 个：

| 区别点 | `var` | `let` |
| --- | --- | --- |
| 作用域 | **函数作用域**，只认函数 | **块级作用域**，认 `{}` |
| 变量提升 | 提升到作用域顶部，值为 `undefined` | 也提升，但有**暂时性死区**，声明前访问直接报错 |
| 重复声明 | 同一作用域可重复声明 | 不允许，报 `SyntaxError` |
| 全局声明时 | 会挂到 `window` 对象上 | 不会 |

**（1）作用域不同（最核心）**

`var` 只认函数，`let` 认任何一对 `{}`（if、for 等都是独立块）：

```js
function demo() {
  if (true) {
    var a = 1;
    let b = 2;
  }
  console.log(a); // 1，var 泄漏到了整个函数
  console.log(b); // 报错 ReferenceError，b 只活在 if 的 {} 里
}
```

**（2）变量提升与暂时性死区（TDZ）**

```js
console.log(x); // undefined（var 提升了，还没赋值）
var x = 10;

console.log(y); // ReferenceError
let y = 20;      // let 声明之前的这段区域叫“暂时性死区”，访问就报错
```

`let` 其实也被提升了，但引擎规定在执行到声明语句之前不允许访问它，避免“变量还没声明就用”的混乱。

**（3）能否重复声明**

```js
var n = 1;
var n = 2; // 合法，后者覆盖前者

let m = 1;
let m = 2; // SyntaxError: Identifier 'm' has already been declared
```

**（4）经典面试题：循环 + 定时器**

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
// 输出：3 3 3 —— 整个循环只有一个 i，循环结束时 i 已经是 3

for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log(j), 0);
}
// 输出：0 1 2 —— 每一轮循环的 {} 都生成一个新的 j
```

> 结论：现代开发中直接用 `let`（常量用 `const`），`var` 只在维护老代码时需要看懂。

### 4.2 条件语句

> 条件语句是编程中常用的结构，用于基于不同的条件执行不同的代码块。

`else if` 语句：用于在上一个 if 语句条件为假时，检查另一个条件。可以有多个 else if 语句。语法如下：

```js
if (condition1) {
    // 如果条件1为真，执行这里的代码
} else if (condition2) {
    // 如果条件2为真，执行这里的代码
} else {
    // 如果以上条件都为假，执行这里的代码
}
```

---

#### 4.2.1 条件语句示例

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>JS基础语法</title>
</head>
<body>
  <script>
    let time = 18;
    //逻辑运算符用 && 和 || 
    if(time < 12) {
      console.log('good morning');
    } else if(12 <= time && time < 18) {
      console.log('good afternoon');
    } else {
      console.log('good evening');     
    }
  </script>
</body>
</html>
```

### 4.3 循环语句

> 循环语句用于重复执行一段代码，直到指定的条件不再满足为止。

`for` 循环：是一种常见的循环结构，用于按照指定的条件重复执行代码块。语法如下：

```js
for (初始化表达式; 循环条件; 迭代器) {
    // 循环体，执行这里的代码
}
```

`while` 循环会在指定的条件为真时执行代码块。语法如下：

```js
while (循环条件) {
    // 循环体，执行这里的代码
}
```

**循环关键字 `break` 与 `continue`**

- `break` 用于跳出循环，结束循环的执行。
- `continue` 用于跳过当前循环中的剩余代码，继续下一次循环。

## 5. JS 函数

> JavaScript 函数

`函数` 是一段可重复使用的代码块，它接受输入（参数）、执行特定任务，并返回输出。

```js
function function_name(参数1, 参数2, 参数3, ...) { // 参数可以不写，表示不传参
    // 函数体，执行这里的代码
    return 返回值; // 可选，返回值
}
```

| --- | --- |
| `onClick` | 点击事件 |

## 7. DOM

> 在 Web 开发中，DOM 通常与 JavaScript 一起使用。

当网页被加载时，浏览器会创建页面的文档对象模型，也就是 DOM（Document Object Model）。

每个 HTML 或 XML 文档都可以被视为一个文档树，文档树是整个文档的层次结构表示。

文档节点是整个文档树的根节点。

DOM 为这个文档树提供了一个编程接口，开发者可以使用 JavaScript 来操作这个树状结构。

### 7.1 DOM示例

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>DOM练习</title>
</head>
<body>
  <div id="box1">这是一个ID选择器标签</div>
  <div class="box2">这是一个类选择器标签</div>
  <div>这是一个普通的div标签</div>

  <button>点击按钮</button>

  <script>
    let element_id = document.getElementById('box1');
    console.log(element_id);  
    
    let element_class = document.getElementsByClassName('box2')[0];
    console.log(element_class);
    
    let element_tag = document.getElementsByTagName('div')[2];
    console.log(element_tag);
    
    // innerHTML会解析html标记
    element_id.innerHTML = '修改后的ID选择器标签';
    // innerText不会解析,只会把里面的内容当作纯文本修改
    element_class.innerText = '修改后的类选择器标签';

    element_tag.style.color = 'red';
    element_tag.style.fontSize = '20px'; 

    // DOM 属性绑定事件
    let button_element = document.getElementsByTagName('button')[0];
    console.log(button_element);
    
    button_element.onclick = function () {
      alert('DOM 属性 按键触发')
    }
    button_element.addEventListener('click', function () {
      console.log('通过addEventListener触发按键');
      
    })
  </script>
</body>
</html>
```

### 7.2 DOM 对象常用方法

| 方法 | 描述 |
| --- | --- |
| `appendChild()` | 把新的子节点添加到指定节点。 |
| `removeChild()` | 删除子节点。 |
| `replaceChild()` | 替换子节点。 |
| `insertBefore()` | 在指定的子节点前面插入新的子节点。 |
| `createAttribute()` | 创建属性节点。 |

| `createTextNode()` | 创建文本节点。 |
