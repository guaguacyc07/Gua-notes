# HTML

## 1. HTML 标签

> **HTML**：全称 `Hypertext Markup Language`，**超文本标记语言**

HTML 通过一系列**标签（也叫元素）**定义文本、图片、链接等内容；HTML标签是尖括号包裹的关键字。

标签通常成对出现，包括开始标签和结束标签（也称为双标签），内容位于这两个标签之间，例如

```html
<p>这是一个段落。</p>
<h1>这是一个标题。</h1>
<a href="#">这是一个超链接。</a>
```

除了双标签，也存在单标签，例如：

```html
<input type="text">
<br>
<hr>
```

区别:

- **单标签**：用于没有内容的元素
- **双标签**：用于有内容的元素

## 2. 常用文本标签

- **标题标签 双标签**

```html
<h1>一级标题</h1>  <!-- 页面最重要标题，一个页面建议只用1次 -->
<h2>二级标题</h2>
<h3>三级标题</h3>
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题</h6>
```

> h1~h6，权重依次降低，自带加粗、上下间距。

- **段落标签**

```html
<p>这是一个段落文本</p>
```

> 段落，段落和段落之间自带间距。

- **换行、分割线（单标签）**

```html
<br>  <!-- 强制换行 -->
<hr>  <!-- 水平分割线 -->
```

- **文本格式化**

```html
<b>加粗</b>        <!-- 视觉加粗，无语义 -->
<strong>加粗</strong> <!-- 加粗，强调，有语义，推荐 -->

<i>斜体</i>        <!-- 视觉斜体，无语义 -->
<em>斜体</em>      <!-- 斜体，表示强调，有语义，推荐 -->

<del>删除线</del>  <!-- 文字中间划横线 -->
<ins>下划线</ins>  <!-- 文字加下划线 -->

<sup>上标</sup>    <!-- 例：2<sup>2</sup> → 2² -->
<sub>下标</sub>    <!-- 例：H<sub>2</sub>O → H₂O -->
```

- **特殊文本**

```html
<pre>
预格式化文本
保留    空格
和换行
</pre>

<small>小号文字</small>
```

- **语义标签（重点）**

  1. `<strong>`：重要内容、强调，**加粗**

  2. `<em>`：语气上的强调，**斜体**

> 区分： `<b>` / `<i>`：只改样子，没有含义； `<strong>` / `<em>`：不仅改样式，告诉浏览器这段文字是重点。

- **完整示例代码**

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>文本标签演示</title>
</head>
<body>
    <h1>主标题</h1>
    <p>这是一个段落。<br>这里换行了</p>
    <hr>
    <p><strong>重点文字</strong>，<em>强调文字</em>，<del>旧价格</del></p>
</body>
</html>
```

- **无序列表**

```html
<ul>
    <li>无序列表元素1</li>
    <li>无序列表元素2</li>
    <li>无序列表元素3</li>
</ul>
```

- **有序列表**

```html

    <li>有序列表元素1</li>
    <li>有序列表元素2</li>
    <li>有序列表元素3</li>
```

## 3. HTML标签属性

> 属性在 HTML 中起到非常重要的作用，它们用于定义元素的行为和外观，以及与其他元素的关系。

- **基本语法**

```html
<开始标签 属性名="属性值">
```

- **每个HTML元素可以具有不同的属性**

```html
<p id="describe" class="section">这是一个段落标签</p>
<a href="https://www.baidu.com">这是一个超链接</a>
```

- **属性名称不区分大小写，属性值对大小写敏感**

```html
<img src="example.jpg" alt="">
<img SRC="example.jpg" alt="">
<img src="EXAMPLE.JPG" alt="">
<!--前两者相同，第三个与前两个不一样-->
```

- **适用于大多数 HTML 元素的属性**

| 属性 | 描述 |
| ---- | ---- |
| class | 为 HTML 元素定义一个或多个类名(类名从样式文件引入) |
| id | 定义元素唯一的 id |
| style | 规定元素的行内样式 |

例如：

```html
<h1 id="title"></h1>
<div class="nav-bar"></div>
<h2 class="nav-bar"></h2>
```

## 4. HTML区块

> 有块元素和行内元素

### 4.1 **块元素（block）**

> 块级元素通常用于组织和布局页面的主要结构和内容，例如段落、标题、列表、表格等。它们用于创建页面的主要部分，将内容分隔成逻辑块。

  - 块级元素通常会从新行开始，并占据整行的宽度，因此它们会在页面上呈现为一块独立的内容块。

  - 可以包含其他块级元素和行内元素。

  - 常见的块级元素包括 `<div>`、`<p>`、`<h1>` 到 `<h6>`、`<ul>`、`<ol>`、`<li>`、`<table>`、`<form>` 等。

### 4.2 **行内元素（inline）**

> 行内元素通常用于添加文本样式或为文本中的一部分应用样式。它们可以在文本中插入小的元素，例如超链接、强调文本等。

  - 行内元素通常在同一行内呈现，不会独占一行。
  - 它们只占据其内容所需的宽度，而不是整行的宽度。
  - 行内元素不能包含块级元素，但可以包含其他行内元素。
  - 常见的行内元素包括 `<span>`、`<a>`、`<strong>`、`<em>`、`<img>`、`<br>`、`<input>` 等。

## 5. HTML表单

### 5.1 表单示例

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML表单练习</title>
</head>
<body>
  <form action="#">
    <!-- label中的for属性绑定了input的id后, 点击文字，就能激活输入框 -->
    <!-- value相当于自动填充了一个值进去 -->
    <label for="username">用户名: </label>
    <input type="text" id="username" value="请输入用户名">
    <br><br>
    <!-- placeholder只是一个提示作用 -->
    <label for="pwd">密码: </label>
    <input type="password" id="pwd" placeholder="请输入密码">
    <br><br><hr>

    <!-- 单选 -->
    <label>性别: </label>
    <input type="radio" name="gender">男
    <input type="radio" name="gender">女
    <input type="radio" name="gender">其他
    <br><br>

    <!-- 多选 -->
    <label>爱好: </label>
    <input type="checkbox" name="hobby">唱
    <input type="checkbox" name="hobby">跳
    <input type="checkbox" name="hobby">rap
    <input type="checkbox" name="hobby">篮球
    <br><br>

    <!-- 提交->(form中的action属性) -->
    <input type="submit" value="上传">
    
  </form>
</body>
</html>
```
